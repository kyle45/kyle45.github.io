## 二、⚠️ 网鼎杯赛制（重要）

```
官方资格赛（线上，分青龙/白虎/朱雀/玄武组）
   ↓
半决赛  ← 三种赛制，含「风险隐患挖掘赛」= 靶场渗透 ★ 渗透在这里
   ↓
总决赛  ← 「网鼎之城守卫赛」——模拟城市网络，
          含能源 / 交通 / 金融 行业的攻防场景
```

**要点：**
- **渗透 = 半决赛的「风险隐患挖掘赛」**，不是决赛
- **决赛 = 「网鼎之城守卫赛」**，城市级、多行业攻防
- 所以"网鼎决赛-渗透赛道"这个说法不准确

## 四、360 办赛的赛制特征

| 特征 | 证据 |
|---|---|
| **A&D 攻防对抗是主场** | 第五空间第 3/4 届决赛、鹤城杯决赛都是 A&D |
| **综合靶场 + 蜜罐** | 360 杯决赛明确"按真实企业网络部署、**穿插蜜罐**"，要求**输出完整攻击拓扑** |
| **应急响应/取证是常设赛道** | 360 杯题型含"数据包分析、取证分析"；鹤城杯含"应急响应与恢复" |
| **新题型常客** | AI / 大模型、鸿蒙、工控 |
| **漏洞挖掘赛** | 第五空间首创，需麒麟软件支撑 |
| **动态 flag + 零和机制** | A&D 10 分钟/回合更新 flag → 需要自动化脚本 |
| **信创环境** | 飞腾 CPU + 麒麟 OS 的 "PK 体系" 是其特色 |

## 六、对备赛的含义

1. **三层网络渗透是确定的主流形式** —— `02`/`07` 覆盖得不错，建议把那套公开环境下下来打一遍
2. **决赛可能是"城市/行业多场景 + 攻防"**，不是纯 CTF → 可能要**防守侧**（监测、防护）+ **事后取证复盘**
3. **A&D 要单独准备** —— 360 多个赛事决赛是 A&D，而现有材料全是进攻视角，**这是最大空白**
4. **蜜罐识别** —— 综合靶场明确穿插蜜罐，踩了可能扣分
5. **工控/关基方向别完全忽略** —— 多行业场景（能源/交通/金融）可能出现协议层、工控类题
6. **大模型安全** —— 360 战略方向（提示注入为其列为四大攻击技战术之首）
7. **信创环境**（麒麟/统信）—— 命令与路径跟 CentOS 有差异
