# 安全加固基线核查手册

> **适用**：线下实战靶场竞赛（操作系统 / 数据库 / 中间件 / Web 四类）
> **形态**：每类给「**核查命令** → **发现问题** → **加固动作**」三段
> **用法**：拿到一个环境，按对应章节自上而下过一遍
> **独立文件**：不改动 `01`–`08`

---

## 0. 通用思路

```
拿到靶机 → ① 识别（系统/服务/版本）→ ② 按基线核查 → ③ 记录发现
         → ④ 若题目要 flag：在"配置错误"处找 → ⑤ 若题目要加固：按加固动作改
```

**两类题目的差别**
| 题目类型 | 你要做的 |
|---|---|
| **找问题型**（给环境找 flag） | 按基线核查，**每一条不合规处都可能藏 flag** |
| **加固型**（改好后才出 flag） | 按基线加固，改对了 flag 出现 |

**通用核查工具**
```bash
# Linux 一把梭
lynis audit system                     # ★ Linux 安全审计，报告很全
lynis show details                     # 看详细建议

# 端口/服务
ss -antp; netstat -antp
nmap -sT -Pn -sV -p- <本机IP>

# Web 安全头/SSL
nmap -p443 --script ssl-enum-ciphers <IP>
nmap -p80,443 --script http-security-headers <IP>
testssl.sh <IP>:443
```

## 1. 操作系统安全

### 1.1 Linux

#### 账户与认证
```bash
# 空口令账户 ★ 高频考点
awk -F: '($2==""){print $1}' /etc/shadow
# UID=0 的非 root 账户 ★
awk -F: '$3==0 {print $1}' /etc/passwd
# 可登录但无用的账户
awk -F: '$7!="/sbin/nologin" && $7!="/bin/false" {print $1,$7}' /etc/passwd
# 密码策略
cat /etc/login.defs | grep -E "PASS_MAX_DAYS|PASS_MIN_LEN|PASS_WARN_AGE"
cat /etc/pam.d/common-password    # 或 system-auth
# 登录失败锁定
cat /etc/pam.d/sshd | grep -E "tally|faillock"
```

**加固动作**
```bash
passwd -l <user>                    # 锁定账户
usermod -L <user>                   # 锁定（另一种）
chage -E0 <user>                    # 立即过期
# 改 /etc/login.defs: PASS_MAX_DAYS 90, PASS_MIN_LEN 8
```

#### SSH 加固 ★ 高频
```bash
cat /etc/ssh/sshd_config | grep -vE "^#|^$"
```
| 应设为 | 说明 |
|---|---|
| `PermitRootLogin no` | 禁 root 直登 |
| `PasswordAuthentication no` | 用密钥 |
| `PermitEmptyPasswords no` | 禁空口令 |
| `MaxAuthTries 3` | 限制尝试 |
| `Port <非22>` | 改默认端口 |
| `AllowUsers <白名单>` | 白名单 |
| `ClientAliveInterval 300` | 超时断开 |
| `Protocol 2` | 老版本 |

```bash
# 改完务必检查语法，否则把自己锁外面
sshd -t
systemctl restart sshd
```

#### 文件权限
```bash
ls -l /etc/passwd /etc/shadow /etc/group /etc/gshadow
# 应为: passwd 644, shadow 000/400, group 644, gshadow 000
# 全局可写文件 ★
find / -perm -0002 -type f 2>/dev/null
# 无主文件
find / -nouser -o -nogroup 2>/dev/null
# SUID/SGID ★（找问题:留下的后门；加固:清理不必要的）
find / -perm -4000 -type f 2>/dev/null
find / -perm -2000 -type f 2>/dev/null
```

#### 服务最小化
```bash
systemctl list-unit-files --state=enabled
systemctl list-units --type=service --state=running
ss -antp                            # 监听端口逐个确认用途
```
**加固**：关闭 telnet / ftp / tftp / rsh / rlogin 等明文服务
```bash
systemctl stop <svc>; systemctl disable <svc>
```

#### 计划任务
```bash
crontab -l
ls -la /etc/cron* /etc/crontab
cat /var/spool/cron/crontabs/* 2>/dev/null
ls -la /etc/cron.d/
atq
```
**加固**：`crontab` 目录权限（`/etc/crontab` 600）、清理可疑任务

#### 内核参数
```bash
sysctl -a 2>/dev/null | grep -E "ip_forward|accept_redirects|syncookies|randomize_va_space"
```
```bash
# /etc/sysctl.conf 加固
net.ipv4.ip_forward = 0
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.tcp_syncookies = 1
net.ipv4.icmp_echo_ignore_broadcasts = 1
kernel.randomize_va_space = 2       # ASLR
```
```bash
sysctl -p
```

#### 日志与审计
```bash
ls -la /var/log/            # 日志文件权限
systemctl status auditd     # 审计服务
cat /etc/audit/audit.rules 2>/dev/null
```

### 1.2 Windows

```cmd
:: === 账户 ===
net accounts                        :: 密码策略 / 锁定策略 ★
net user                            :: 账户列表（$ 结尾 = 隐藏账户）★
net localgroup administrators       :: 管理员组成员
wmic useraccount get name,sid,disabled

:: === 安全检查 ===
secpol.msc                          :: 本地安全策略
gpedit.msc                          :: 组策略

:: === 服务与端口 ===
services.msc
sc query state= all
netstat -anob
net share                           :: 默认共享 ★

:: === 补丁 ===
wmic qfe get Caption,Description,HotFixID,InstalledOn
systeminfo | findstr /i "hotfix"

:: === 启动项 ===
reg query HKLM\Software\Microsoft\Windows\CurrentVersion\Run
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run
schtasks /query /fo LIST /v
```

**关键加固项**
| 项 | 动作 |
|---|---|
| Guest 账户 | 禁用 |
| Administrator | 重命名 |
| 默认共享 | `net share C$ /delete`（临时）；注册表 `AutoShareWks=0` |
| RDP | 启用 NLA、改端口、限制来源、锁定策略 |
| 匿名访问 | `HKLM\SYSTEM\CurrentControlSet\Control\Lsa\` → `RestrictAnonymous=1` |
| 空口令限制 | `LimitBlankPasswordUse=1` |
| 自动登录 | 删 `AutoAdminLogon` |
| Autorun | `NoDriveTypeAutoRun=0xFF` |
| 审核策略 | `auditpol /set /category:* /success:enable /failure:enable` |
| 日志大小 | 加大安全日志上限 |
| 不必要服务 | Remote Registry、Print Spooler、Telnet 等停用 |

## 2. 数据库安全

### 2.1 MySQL

```sql
-- === 核查 ===
SELECT user, host, authentication_string FROM mysql.user;    -- ★ 匿名用户 / 远程root
SHOW VARIABLES LIKE '%secure_file_priv%';                    -- ★ 应为非空
SHOW VARIABLES LIKE 'local_infile';                          -- 应为 OFF
SHOW VARIABLES LIKE 'validate_password%';
SELECT * FROM mysql.user WHERE User='';                      -- 匿名用户 ★
SELECT user,host FROM mysql.user WHERE User='root' AND Host NOT IN ('localhost','127.0.0.1','::1');  -- 远程 root ★
SHOW GRANTS FOR 'user'@'host';                               -- ★ 权限是否过大
SHOW VARIABLES LIKE 'port';
SHOW DATABASES;                                              -- test 库应删
```

**加固动作**
```sql
-- 删匿名用户
DELETE FROM mysql.user WHERE User='';
-- 限远程 root
DELETE FROM mysql.user WHERE User='root' AND Host NOT IN ('localhost','127.0.0.1','::1');
-- 回收危险权限
REVOKE FILE, SUPER, PROCESS, SHUTDOWN ON *.* FROM 'user'@'host';
-- 删 test 库
DROP DATABASE IF EXISTS test;
FLUSH PRIVILEGES;
```
```bash
# 配置文件加固 /etc/my.cnf 或 my.ini
# secure_file_priv = /var/lib/mysql-files      ← 非空且受限
# local_infile = 0
# skip-symbolic-links
# port = 非3306
# 开日志: general_log = 1 / binlog
mysql_secure_installation        # ★ 交互式加固脚本（改 root 密码、删匿名、禁远程 root、删 test）
```

**注入防御**
```bash
# 找注入点
sqlmap -u "http://target/x?id=1" --batch --dbs
# 修复：参数化查询（代码层）/ WAF 规则 / 最小权限（能减少注入影响）
```

**数据脱敏**
```sql
-- 识别敏感字段
SELECT COLUMN_NAME, TABLE_NAME FROM information_schema.COLUMNS
WHERE COLUMN_NAME REGEXP 'id_card|phone|mobile|card|bank|email|address|name';
```
脱敏方式：掩码（`138****1234`）/ 哈希 / 泛化（精确到市）/ 假名化

### 2.2 Redis

```bash
redis-cli -h <IP> ping            # 未授权访问测试 ★
redis-cli -h <IP> config get bind
redis-cli -h <IP> config get requirepass
redis-cli -h <IP> config get protected-mode
```
**加固**
```conf
# redis.conf
bind 127.0.0.1
requirepass <强口令>
protected-mode yes
rename-command CONFIG ""
rename-command FLUSHALL ""
rename-command EVAL ""
```
```bash
# 禁止 root 运行、用独立低权账户
# 检查是否有 SSH key / cron 被写 ★
ls -la ~/.ssh/authorized_keys
cat /var/spool/cron/crontabs/root
```

### 2.3 MSSQL

```sql
-- 核查
SELECT * FROM sys.configurations WHERE name IN ('xp_cmdshell','Ole Automation Procedures');
SELECT name, is_disabled FROM sys.server_principals;   -- sa 是否禁用
```
```sql
-- 加固
EXEC sp_configure 'xp_cmdshell', 0; RECONFIGURE;
EXEC sp_configure 'Ole Automation Procedures', 0; RECONFIGURE;
ALTER LOGIN sa DISABLE;
```
另：改默认端口 1433、强口令、最小权限

### 2.4 PostgreSQL

```bash
cat /etc/postgresql/*/main/pg_hba.conf      # ★ trust 认证 = 大问题
cat postgresql.conf | grep -E "listen_addresses|ssl"
```
**加固**：`pg_hba.conf` 用 `md5`/`scram-sha-256`，禁 `trust`；限制 `listen_addresses`

## 3. 中间件安全

### 3.1 Tomcat ★ 高频

```bash
# 版本泄露
curl -I http://<IP>:8080/                    # Server: Apache-Coyote/1.1
curl http://<IP>:8080/docs/                  # ★ 默认应用是否还在
curl http://<IP>:8080/examples/
curl http://<IP>:8080/manager/html           # ★ 管理界面暴露
curl http://<IP>:8080/host-manager/html
```

**加固清单**
| 项 | 动作 |
|---|---|
| **删默认应用** | 删除 `webapps/` 下 `docs`、`examples`、`manager`、`host-manager` |
| **管理口令** | `conf/tomcat-users.xml` 强口令 + 最小角色；不用就注释掉 |
| **禁用 PUT** | `conf/web.xml` 里 DefaultServlet 加 `<readonly>true</readonly>` |
| **关闭 AJP** | `server.xml` 注释 `AJP/1.3` Connector，或设 `secretRequired="true"` + 强 secret |
| **隐藏版本** | `server.xml` 的 `<Connector ... server="XXX"/>` |
| **错误页** | 自定义 404/500，不泄露版本与堆栈 |
| **管理端口** | `<Context>` 加 RemoteAddrValve 限制来源 IP |
| **运行用户** | 用非 root 低权用户 |
| **关闭目录列表** | `listings` 设 false |

```xml
<!-- 限制 manager 来源 -->
<Context path="/manager" docBase="manager">
  <Valve className="org.apache.catalina.valves.RemoteAddrValve"
         allow="127\.0\.0\.1"/>
</Context>
```

### 3.2 Apache httpd

```bash
httpd -v                              # 版本
curl -I http://<IP>/                  # Server 头
curl http://<IP>/icons/               # 目录列表?
curl http://<IP>/server-status        # ★ 状态页暴露
```
**加固**
```conf
ServerTokens Prod                     # ★ 只说 Apache，不报版本
ServerSignature Off
<Directory /var/www/html>
    Options -Indexes                  # ★ 禁目录列表
    AllowOverride None
</Directory>
<Location /server-status>
    Require local                     # 限制状态页
</Location>
# 限制 HTTP 方法
<LimitExcept GET POST>
    Require all denied
</LimitExcept>
# 安全响应头
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "DENY"
Header always set Strict-Transport-Security "max-age=31536000"
```

### 3.3 Nginx

```bash
nginx -v
curl -I http://<IP>/
```
**加固**
```conf
server_tokens off;                    # ★ 隐藏版本
autoindex off;                        # ★ 禁目录列表
# 限制方法
if ($request_method !~ ^(GET|POST)$ ) { return 405; }
# 安全响应头
add_header X-Frame-Options "DENY";
add_header X-Content-Type-Options "nosniff";
add_header Content-Security-Policy "default-src 'self'";
add_header Referrer-Policy "no-referrer";
# 限制上传大小
client_max_body_size 10m;
# 隐藏后端
proxy_hide_header X-Powered-By;
```

### 3.4 Web 应用安全响应头（通用速查）

| 头 | 推荐值 | 防什么 |
|---|---|---|
| `Content-Security-Policy` | `default-src 'self'` | XSS |
| `Strict-Transport-Security` | `max-age=31536000` | 降级攻击 |
| `X-Frame-Options` | `DENY` | 点击劫持 |
| `X-Content-Type-Options` | `nosniff` | MIME 嗅探 |
| `Referrer-Policy` | `no-referrer` | 信息泄露 |
| `Set-Cookie` | `HttpOnly; Secure; SameSite=Strict` | XSS 窃 Cookie / CSRF |

## 4. Web 应用防护与渗透

### 4.1 找漏洞（渗透视角）

| 漏洞 | 探测 |
|---|---|
| SQL 注入 | `sqlmap -u "...?id=1" --batch --dbs`；手工 `'`、`and 1=1` |
| 文件上传 | 试 `.php`、`.phtml`、`.php5`、`.user.ini`、`.htaccess`、双写、%00、内容头 |
| 命令执行 | `;id`、`|id`、`$(id)`、反引号 |
| 目录穿越 | `../../etc/passwd`、编码变体 |
| 反序列化 | 看 Cookie/参数是否 base64、看框架版本 |
| XSS | `"><script>alert(1)</script>` |
| SSRF | `url=http://127.0.0.1:port` |
| 越权 | 改 ID / 改角色参数 |
| 敏感信息泄露 | `/backup.zip`、`/.git/config`、`/phpinfo.php`、错误页堆栈 |

### 4.2 防护/修复（加固视角）

| 漏洞 | 修复 |
|---|---|
| SQL 注入 | **参数化查询**（根本）；WAF 规则；最小权限 DB 账户 |
| 文件上传 | 白名单后缀 + 内容校验 + 重命名 + 存储目录不可执行 |
| 命令执行 | 避免拼接；白名单；`escapeshellarg` |
| XSS | 输出编码 + CSP |
| CSRF | CSRF Token + `SameSite` |
| SSRF | 白名单目标 + 禁内网段 + 禁协议 |
| 目录穿越 | `realpath` 归一化后校验前缀 |
| 敏感信息 | 关调试模式、自定义错误页、删备份文件、`.git` 不可访问 |

### 4.3 WAF / 安全设备规则（若赛场有）

- 常见：Web 防火墙、下一代防火墙、日志审计
- 规则方向：拦截 SQL 注入特征、拦截 webshell 上传、限速防爆破、封 IP

## 5. 考场速查：拿到一个环境先做什么

```
① 识别
   Linux:  cat /etc/os-release; uname -a; ss -antp; systemctl list-units --type=service --state=running
   Win:    systeminfo; netstat -anob; services.msc; net user

② 按四类核查（本文 1-4 章）
   操作系统 → 数据库 → 中间件 → Web

③ 记录发现（每条不合规都可能是答案）

④ 判断题目类型
   找问题型 → 在不合规处找 flag
   加固型   → 按加固动作改，改对后出 flag

⑤ 时间管理（3.5 小时、统一赛题）
   先扫一遍全会做的 → 卡住就跳 → 上一题做完再进下一题
   （每题独立环境，不需要攒代理链）
```

## 6. 高频考点速记（背这几条）

**Linux**
1. 空口令账户 `awk -F: '($2==""){print $1}' /etc/shadow`
2. UID=0 非 root 账户
3. SUID 后门 `find / -perm -4000`
4. SSH 配置（PermitRootLogin / PasswordAuthentication）
5. `/etc/shadow` 权限
6. 可疑 cron

**Windows**
1. `net accounts`（密码策略）
2. 隐藏账户（`$` 结尾）+ **克隆账户**
3. 默认共享
4. 缺失补丁
5. 异常服务 / 启动项
6. RDP 配置

**数据库**
1. MySQL 匿名用户 / 远程 root / `secure_file_priv`
2. Redis 未授权 + `requirepass`
3. MSSQL `xp_cmdshell`

**中间件**
1. Tomcat 默认应用（docs/examples/manager）+ PUT + AJP
2. Apache `ServerTokens` / `-Indexes`
3. Nginx `server_tokens off` / `autoindex off`

**Web**
1. 安全响应头 6 件套
2. Cookie 的 `HttpOnly / Secure / SameSite`
3. 上传白名单、参数化查询
