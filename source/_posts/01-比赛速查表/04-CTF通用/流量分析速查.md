# 流量分析 / 应急溯源 速查手册

> 面向：渗透 + 应急溯源方向的 CTF / 技能竞赛
> 用法：比赛时打开，按「0 工作流 → 1 问题清单 → 对应章节」的顺序查

## 0. 通用工作流（固定四步，别跳）

```
1. 定性质    file / capinfos 看协议分布、包数、时间跨度
2. 分层看    协议统计 → 会话（谁跟谁通）→ 挑可疑 IP
3. 找攻击链  漏洞特征 → 利用成功 → 落地文件 → 影响面
4. 提答案    按「高频问题清单」逐条对着找，别漫游
```

**纪律两条**
- 所有操作在**副本**上做，原始附件不动
- **边做边记**：答题卡制，答案格式严，最后回忆必错

## 2. Shiro rememberMe 反序列化（贵州真题考点）

**识别特征**
- HTTP 请求 Cookie 里有 `rememberMe=deleteMe` 或一长串 base64
- 响应里常返回 `rememberMe=deleteMe`（表示解密失败的重置）

**处理流程**

```bash
# 1. 解析 cookie 里的序列化数据（默认 100 key 碰撞）
java -jar SerializationDumper-Shiro.jar -s <cookie的值>

# 输出会告诉你：
#   [+] Shiro Cookie 加密密钥为：fCq+/xW488hMTCD+cmJ3aQ==   ← 撞出来的 key
#   [+] 使用的 Gadget 为 TemplatesImpl
#   bytecodes 中的代码存放在 bytecodes.class
```

**要点**
- 默认碰撞的是**广泛流传的 100 key**
- Gadget 常见 `TemplatesImpl`，其 `bytecodes` 存到 `bytecodes.class`，**用 IDEA 打开就能看攻击者执行的代码**
- **看最后一个 HTTP 响应包**：从数据特征（文件头 / Content-Type / Content-Disposition）判断**下载了什么文件**
- 答案形式常为 `flag{该文件的MD5值}`

**工具**：`https://github.com/r00tuser111/SerializationDumper-Shiro`

## 3. SQL 盲注爆破流量（贵州真题考点，必考写脚本）

**识别特征**
- 大量 GET 请求，URI 里是逐位比较：`and ascii(substr((select flag from answer),N,1))=M`
- 请求 URI 高度相似，只有 N 和 M 在变

**判定「爆破成功」的包**
- 响应体长度有特征（真题里是 `http.data` 长度 **704**）
- 响应含特征关键词（真题里是 **`You are in`**）

**必须写脚本 —— 手工跟包必死**

```python
# exp.py  (pyshark)
import pyshark, re, time

strCapPath   = "wireshark.pcapng"
strTsharkPath = r"C:\Program Files\Wireshark"   # Linux 下可省略

f  = 'http.request.uri contains "Less-5/"'
f += ' && http.request.full_uri contains "((select%20flag%20from%20answer)"'
f += ' && http.file_data contains "You are in"'

cap = pyshark.FileCapture(strCapPath, display_filter=f, tshark_path=strTsharkPath)

lstResult = ['', '', '', '']
for pkt in cap:
    uri = pkt.http.request_uri
    m = re.search(r'answer\),(.*?),1\)\)=(.*?)--+', uri)
    if not m:
        continue
    pos, ch = int(m[1]), int(m[2])
    while len(lstResult) <= pos:
        lstResult.append('')
    lstResult[pos] = chr(ch)

print(''.join(lstResult))
```

**不想写 pyshark 的一行替代（tshark）**

```bash
tshark -r x.pcapng -Y 'http.request.uri contains "select"' \
       -T fields -e http.request.uri | \
  grep -oP 'answer\),\K\d+(?=\),1\)\)=\d+)' 
# 再配一遍取字符，或者直接 awk 拼
```

**同类变体**：SQL 注入日志（不是流量）也是同一套 —— 正则提取被窃取的姓名/身份证号，**并用 Python 算出 MD5 提交**。

## 4. Webshell 流量特征（蚁剑 / 冰蝎 / 哥斯拉）

| 类型 | 特征 | 默认密码 |
|---|---|---|
| **蚁剑 AntSword** | POST 体带 `@ini_set("display_errors","0");@set_time_limit(0);` + base64；UA 含 `antSword` | 自设 |
| **冰蝎 Behinder** | 请求体 AES 加密、`Content-Length` 固定偏小；Accept 头异常；响应体二进制 | **rebeyond** |
| **哥斯拉 Godzilla** | payload 前后带固定 md5 前缀（key 的 md5 前 16 位 + 后 16 位） | 自设 |
| **一句话** | `eval($_POST['xxx'])`，POST 参数名就是密码 | 看源码 |

**排查动作**：找 webshell **文件名** → 找**连接密码** → 找第一次上传它的请求（定位漏洞点）

## 5. 内存 / 日志 / 磁盘 取证

### 5.1 内存镜像（Volatility）

```bash
# --- Volatility 2 （老镜像优先）---
vol.py -f mem.img imageinfo                # 先确定 profile
vol.py -f mem.img --profile=Win7SP1x64 pslist   # 进程
vol.py -f mem.img --profile=... pstree
vol.py -f mem.img --profile=... netscan    # 网络连接（找 C2、找向日葵）
vol.py -f mem.img --profile=... cmdline    # 进程命令行
vol.py -f mem.img --profile=... filescan   # 找文件对象
vol.py -f mem.img --profile=... dumpfiles -Q 0x<addr> -D out/   # 导出文件
vol.py -f mem.img --profile=... hivelist
vol.py -f mem.img --profile=... printkey -K "Software\Microsoft\Windows\CurrentVersion\Run"

# --- Volatility 3 （新镜像）---
vol3 -f mem.img windows.info
vol3 -f mem.img windows.pslist
vol3 -f mem.img windows.netscan
vol3 -f mem.img windows.filescan
vol3 -f mem.img windows.dumpfiles --virtaddr 0x...
```

**坑**：中文路径编码问题 → `set PYTHONIOENCODING=utf-8` 或 `chcp 65001`；部分镜像 vol2 读不了、vol3 能读，**两个都备着**。

**GUI 一把梭**：**LovelyMem**（`github.com/Tokeii0/LovelyMem`）—— 国内应急赛推荐，省一半时间。

**常见答案来源**
- `dumpfiles` 导出后看图片/文档 → flag 常在里面
- `netscan` 找异常外联（向日葵 SunloginClient、AnyDesk 的内网 IP）
- 注册表 Run 键 / `hivelist` → 持久化
- `rundll32.exe comsvcs.dll, MiniDump` → 攻击者导 lsass 的动作

### 5.2 日志

**Linux**
- `/var/log/auth.log`、`/var/log/secure` → 登录、sudo、爆破
- `/var/log/nginx/access.log`、`apache2/access.log` → 攻击者 IP、webshell、注入
- `~/.bash_history` → **最直接**，攻击者的命令历史
- `/etc/cron*`、`/etc/passwd`、`/etc/sudoers`

**Windows 事件 ID**

| ID | 含义 |
|---|---|
| 4624 | 登录成功 |
| 4625 | 登录失败 |
| 4720 | **创建用户** ← 找隐藏账户创建时间 |
| 4722 | 账号启用 |
| 4726 | 删除用户 |
| 4688 | 进程创建 |
| 7045 | **服务安装**（持久化） |

**国产设备日志路径示例**：瑞友天翼 `C:\Program Files (x86)\RealFriend\Rap Server\Logs\access.log`

### 5.3 磁盘 / 文件分离

```bash
foremost -i x.bin -o out/        # 分离（附件先分离再用 wireshark 打开是常见套路）
binwalk -e x.bin                 # 同上，带递归
strings x.bin | grep -i flag     # 快速捞
```
- **Autopsy** → 看文件元数据（**最后修改时间常是答案**：网页被篡改时间）
- **DiskGenius** → 恢复删除文件 + 隐写

## 6. 常用命令速查

```bash
file x.bin                       # 先看真身（很多题第一层是文件分离）
capinfos x.pcapng                # 流量包概览
tshark -r x.pcapng -z io,phs     # 协议分层统计
tshark -r x.pcapng -Y 'http' -T fields -e http.host -e http.request.uri | sort | uniq -c | sort -rn
tshark -r x.pcapng -Y 'http.request.method==POST' -T fields -e http.file_data
md5sum file                      # 提交前核对（注意题目要求大小写）
```

## 7. 现场纪律

1. **先备份附件，所有操作在副本上**
2. **按「问题清单」过一遍**，别漫游
