# 应急响应速查

## Windows 重点事件

| Event ID | 含义 |
|---|---|
| 4624 | 登录成功 |
| 4625 | 登录失败 |
| 4648 | 显式凭据登录 |
| 4672 | 特殊权限登录 |
| 4688 | 进程创建 |
| 4720 | 创建用户 |
| 4732 | 加入本地管理员组 |
| 7045 | 安装服务 |

## Windows 排查

```cmd
tasklist /v
tasklist /svc
netstat -ano
net user
net localgroup administrators
schtasks /query /fo LIST /v
sc query type= service state= all
wmic startup get caption,command
```

重点目录：

```text
C:\Windows\Temp
C:\Users\Public
C:\ProgramData
C:\Windows\System32\Tasks
C:\Windows\System32\drivers\etc\hosts
```

持久化检查：

- 服务、计划任务、启动目录、Run 注册表键。
- WMI 事件订阅、Winlogon、IFEO、AppInit_DLLs。
- Web 目录木马、后门账号、异常监听端口。

## Linux 排查

```bash
ps aux
ss -lntp
netstat -antp
crontab -l
cat /etc/crontab
ls -la /etc/cron*
systemctl list-units --type=service
cat /etc/passwd
awk -F: '$3==0{print $1}' /etc/passwd
```

重点目录：

```text
/tmp
/var/tmp
/dev/shm
/var/www
/home
/root/.ssh
```

## 处置顺序

1. 隔离主机或限制网络，保留现场。
2. 确认异常账号、进程、端口、服务、计划任务。
3. 查找入口：Web 日志、认证日志、漏洞版本、上传文件。
4. 查找持久化与横向痕迹。
5. 记录 IOC：文件 Hash、IP、域名、账号、进程路径。
6. 清除后门并修改密码/密钥，再恢复业务。
