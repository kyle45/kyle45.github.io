## 0. 先看这 5 行，不然会懵

**比赛在干什么**
给你一台机器（叫"靶机"），里面留着别人攻击过的痕迹。你要从中找出**特定问题的答案**（叫 flag），提交到竞赛平台，答对得分。

**你要做的三件事**
1. **照抄命令** → 回车 → 看结果
2. **对照本文的「什么叫可疑」** → 判断有没有问题
3. **把可疑的东西记下来**（纸上或记事本）

**三条铁律**
- ❗ **不要改配置、不要删文件、不要重启服务**（除非题目明确说"加固/修复"）
- **看不懂就跳过**，别死磕，先把会的做完
- **边做边记**，答案先记下来，最后统一提交

**一句安慰**：这比赛 3.5 小时、题目固定，**大部分分数靠"照着清单做完"，不靠聪明**。

## 1. 开局体检：把这一整块挨个跑一遍

```bash
# ===== 一条一条敲，每条都看看输出 =====

# ① 我在哪台机器上
hostname; id; cat /etc/os-release

# ② 谁在监听端口 / 有哪些网络连接
netstat -antp 2>/dev/null || ss -antp

# ③ 有哪些进程在跑
ps aux

# ④ 有哪些用户
cat /etc/passwd

# ⑤ 谁登录过（成功 / 失败）
last | head -20
lastb | head -20

# ⑥ 有没有定时任务
crontab -l 2>/dev/null
cat /etc/crontab
ls -la /etc/cron* 2>/dev/null

# ⑦ 执行过的命令历史 ★ 最常出答案
cat ~/.bash_history 2>/dev/null
cat /root/.bash_history 2>/dev/null

# ⑧ 临时目录里有什么（木马爱藏这）
ls -la /tmp /var/tmp /dev/shm

# ⑨ 环境变量（flag 有时藏这）
env

# ⑩ 最近 7 天被改过的文件
find / -mtime -7 -type f 2>/dev/null | head -50
```

### 每条命令「看什么」

| # | 命令 | 什么叫可疑 |
|---|---|---|
| ① | hostname / id | 先确认自己是普通用户还是 root |
| ② | netstat | **陌生的监听端口**；连到**外网**的连接 |
| ③ | ps aux | 名字**乱码/奇怪**的进程；从 `/tmp` 启动的进程 |
| ④ | passwd | 你不认识的名字；**UID 是 0 但不是 root** |
| ⑤ | lastb | **大量失败登录** = 有人在爆破 |
| ⑥ | cron | 你不认识的定时任务 |
| ⑦ | history | **攻击者敲过的命令，直接告诉你一切** ★★★ |
| ⑧ | /tmp | 任何 `.sh` / `.py` / 可执行文件都值得看 |
| ⑨ | env | 有奇怪字符串 → **可能就是 flag** |
| ⑩ | find | 攻击时间附近被改动的文件 |

## 2. 「正常」vs「异常」对照表

| 项目 | 正常 | 异常（要记下来） |
|---|---|---|
| **监听端口** | 22(SSH)、80/443(Web)、3306(MySQL) | 4444、8888、1337、10000+ 的陌生端口 |
| **进程名** | `nginx`、`mysqld`、`sshd` | 随机字符串、一堆数字、`kworker` 冒牌 |
| **进程路径** | `/usr/sbin/nginx` | `/tmp/xxx`、`/var/tmp/xxx`、`/dev/shm/xxx` |
| **用户** | root、你的用户名 | `hack`、`test`、`admin$`（**$ 结尾是隐藏账户**） |
| **定时任务** | 系统自带、你认识的 | 每隔几分钟跑一次的、带 curl/wget/base64 的 |
| **文件位置** | `/usr/bin`、`/etc` | `/tmp`、`/var/tmp`、`/dev/shm`、Web 目录 |
| **Web 目录文件** | `index.php`、`config.php` | `shell.php`、`1.php`、`test.php`、**很小但名字正常的 .php** |

## 3. 答案通常长什么样（认得出才知道找到了）

| 类型 | 样子 | 例子 |
|---|---|---|
| **IP** | 四段数字 | `192.168.126.1` |
| **密码** | 明文或 32 位十六进制 | `Network2020` / `f6f6eb5ace977d7e114377cc7098b7e3` |
| **文件名** | 带后缀 | `shell.php` |
| **路径** | 以 `/` 开头（Linux）或 `C:\` （Windows） | `/var/www/html/x.php` |
| **MD5** | **32 位**十六进制 | `4d6d9c0e6d8492708ff91bef790f4b11` |
| **时间** | 日期+时间 | `2024-09-22 13:15:11` |
| **flag** | 有花括号 | `flag{xxxxx}` |

> **看到 32 位十六进制** → 很可能是 MD5，题目要求"提交 MD5"时就用得上。
> **16 位十六进制** → 很可能是 MD5 的**前 16 位**（webshell 密码常见）。

## 4. 按「题目问什么」去找（★ 最实用的一节）

### 问「攻击者 IP」

```bash
# Web 日志里统计（最常用）
cat access.log | cut -d ' ' -f 1 | sort | uniq -c | sort -nr | head -20

# 只看访问过某个可疑文件的 IP
cat access.log | grep shell.php | cut -d ' ' -f 1 | sort | uniq -c | sort -nr

# 登录成功记录
grep "Accepted" /var/log/auth.log
last -i
```
**找日志文件**：
```bash
ls -la /var/log/
find / -name "access.log*" 2>/dev/null
find / -name "*.log" 2>/dev/null | head -30
```
> ⚠️ **日志里会混很多扫描器的 IP**。真正的攻击者是**访问过 webshell** 或**登录成功**的那个。

### 问「webshell 文件名 / 密码」

```bash
# 找一句话木马
grep -rn "@eval(" /var/www/ 2>/dev/null
grep -rn 'eval($_POST' /var/www/ 2>/dev/null

# 找最近被改动的 php 文件
find /var/www -mtime -7 -name "*.php" -ls 2>/dev/null

# 找文件名可疑的
find /var/www -name "shell*" -o -name "1.php" -o -name "test.php" 2>/dev/null
```

### 问「隐藏账户 / 新建账户」

```bash
awk -F: '$3==0 {print $1}' /etc/passwd        # UID=0 但不是 root ★
awk -F: '($2==""){print $1}' /etc/shadow      # 空口令账户 ★
cat /etc/passwd                                # 看 $ 结尾的
```
```cmd
:: Windows
net user                    :: 注意 $ 结尾的（隐藏账户）
net localgroup administrators
```

### 问「密码」

```bash
cat ~/.bash_history                            # ★ 最常见
grep -rn "password" /var/www 2>/dev/null
cat /var/www/html/*/config*.php 2>/dev/null    # Web 配置里的数据库密码
cat ~/.my.cnf 2>/dev/null
env
```
**16 位十六进制密码** → 去 MD5 在线站**反查明文**

### 问「木马 / 恶意文件路径」

```bash
ls -la /tmp /var/tmp /dev/shm                  # ★ 三件套
find / -name "*.elf" -o -name "*.sh" 2>/dev/null | grep -E "/tmp|/var/tmp|/dev/shm"
cat /proc/<可疑PID>/exe                        # 看进程的真实文件路径
```

### 问「挖矿 / 矿池地址」

```bash
top -c                                          # 看 CPU 最高的进程
cat /proc/<PID>/cmdline | tr '\0' ' '           # 完整命令行 ★
strings <可疑文件> | grep -iE "stratum|pool|xmr"
cat /etc/crontab                                # 挖矿常藏在定时任务里
```

### 问「持久化方式」

```bash
crontab -l
ls -la /etc/cron* /var/spool/cron/crontabs/
cat /etc/rc.local 2>/dev/null
systemctl list-units --type=service
ls -la ~/.config/systemd/user/
```

### 问「时间点」

```bash
stat <文件>                                     # 三个时间戳
ls -la --time-style=full-iso <文件>
find / -newermt "2024-01-01" -type f 2>/dev/null
```

### 问「被删的文件 / 隐藏的东西」

```bash
ls -la                                          # 看 . 开头的隐藏文件
ls -la /root /home/*/ 2>/dev/null
find / -name ".*" -type f 2>/dev/null | head -30
```

## 5. 五类场景：照着一路做下去

### 场景 A：Web 服务器被入侵
```
① 找日志目录
   ls -la /var/log/; find / -name "access.log*" 2>/dev/null
② 统计 IP
   cat access.log | cut -d ' ' -f 1 | sort | uniq -c | sort -nr | head
③ 找 webshell
   grep -rn "@eval(" /var/www/ 2>/dev/null
④ 找攻击者做过什么
   cat ~/.bash_history; cat /root/.bash_history
⑤ 找新建账户
   awk -F: '$3==0 {print $1}' /etc/passwd
⑥ 找持久化
   crontab -l; ls -la /etc/cron*
```

### 场景 B：主机被挖矿（CPU 高）
```
① top -c                        看哪个进程吃 CPU
② cat /proc/<PID>/cmdline | tr '\0' ' '      看它的完整命令
③ ls -la /proc/<PID>/exe                     看真实文件路径
④ cat /tmp/*.sh /var/tmp/* 2>/dev/null       看脚本内容
⑤ cat /etc/crontab; crontab -l               挖矿常靠定时任务存活
⑥ strings <挖矿文件> | grep -iE "stratum|pool"   找矿池
```

### 场景 C：钓鱼邮件（给一个 .eml 文件）
```
① 在邮件里搜 from
   grep -i "^from" mail.eml
② 邮件正文/附件是 base64 编码的 → 解码
   cat 正文.txt | base64 -d
   base64 -d < 附件.b64 > 附件.zip     然后解压
③ 附件是 exe/zip → 记下文件名和 MD5
   md5sum <文件>
```

### 场景 D：给一个流量包（.pcap / .pcapng）
```
① 用 Wireshark 打开
② 菜单：统计 → 会话        看哪个 IP 在跟谁通信
③ 菜单：File → Export Objects → HTTP   ★ 一键导出所有传输的文件
④ 找 webshell 特征：
   - 请求里带 @ini_set("display_errors","0");  → 蚁剑
   - Cookie 里 rememberMe=                     → Shiro 漏洞
⑤ 需要批量提取 → 找队友写脚本（见第 7 节分工）
```

### 场景 E：给一个内存镜像（.raw / .mem / .vmem）
```
① 先看有没有 Volatility，没有就找队友
② 逐条跑：
   vol.py -f mem.raw windows.info        看系统信息
   vol.py -f mem.raw windows.pslist      看进程
   vol.py -f mem.raw windows.netscan     看网络连接（已断开的也有）★
   vol.py -f mem.raw windows.cmdline     看进程完整命令行 ★
   vol.py -f mem.raw windows.filescan    看文件
   vol.py -f mem.raw windows.hashdump    看密码哈希
③ 导出文件：
   vol.py -f mem.raw windows.dumpfiles --physaddr 0x<地址>
```

## 8. 禁区（别做这些，会坏事）

| ❌ 不要做 | 为什么 |
|---|---|
| 改配置文件 | 除非题目说"加固/修复"，否则可能直接判失败 |
| 删文件 | 会破坏证据 |
| 重启服务 / 重启机器 | 内存里的证据全没了 |
| 乱跑扫描器（`nmap` 全端口扫） | 有的环境**扫了会封 IP / 扣分** |
| 凭记忆填答案 | 格式错就白丢分，**一定回原文核对** |

## 9. 一页纸速查（考前背这个）

```bash
# ===== 体检 =====
hostname; id
netstat -antp                    # 端口
ps aux                           # 进程
cat /etc/passwd                  # 用户
last; lastb                      # 登录
crontab -l; cat /etc/crontab     # 定时任务
cat ~/.bash_history              # ★ 历史命令
ls -la /tmp /var/tmp /dev/shm    # ★ 临时目录
env                              # ★ 环境变量

# ===== 找答案 =====
# 攻击者 IP
cat access.log | cut -d ' ' -f 1 | sort | uniq -c | sort -nr | head
# webshell
grep -rn "@eval(" /var/www/ 2>/dev/null
# 隐藏账户（UID=0 非 root）
awk -F: '$3==0 {print $1}' /etc/passwd
# 挖矿
top -c; cat /proc/<PID>/cmdline | tr '\0' ' '
# MD5
md5sum <文件>
```

**三个"最"**
- 最常出答案的地方：**`~/.bash_history`** 和 **`/tmp` / `/var/tmp` / `/dev/shm`**
- 最容易被忘了找的地方：**日志的旧文件**（`access.log.1`、`.gz`）、**别的用户的家目录**（`/home/*/`、`/root/`）
- 最容易丢分的：**答案格式**（MD5 大小写、路径斜杠、带不带 `flag{}`）
