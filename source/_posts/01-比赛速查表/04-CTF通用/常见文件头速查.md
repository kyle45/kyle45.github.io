# 常见文件头速查

| 类型 | 文件头 | 说明 |
|---|---|---|
| PNG | `89 50 4E 47 0D 0A 1A 0A` | 文件尾 `49 45 4E 44 AE 42 60 82` |
| JPG | `FF D8 FF` | 文件尾 `FF D9` |
| GIF | `47 49 46 38` | `GIF87a` / `GIF89a` |
| BMP | `42 4D` | `BM` |
| ZIP | `50 4B 03 04` | 空压缩包可见 `50 4B 05 06` |
| RAR | `52 61 72 21 1A 07 00` | RAR4 / RAR5 |
| 7z | `37 7A BC AF 27 1C` | 7-Zip |
| GZIP | `1F 8B` | gzip |
| PDF | `25 50 44 46` | `%PDF` |
| ELF | `7F 45 4C 46` | Linux 可执行文件 |
| PE | `4D 5A` | Windows EXE / DLL |
| SQLite | `53 51 4C 69 74 65 20 66 6F 72 6D 61 74 20 33 00` | `SQLite format 3` |
| RIFF | `52 49 46 46` | WAV / AVI / WEBP 等 |
| OGG | `4F 67 67 53` | OggS |
| FLAC | `66 4C 61 43` | fLaC |
| MP3 | `49 44 33` | ID3 |

## 使用方式

```bash
file target
xxd target | head
strings -a target | head
binwalk target
```
