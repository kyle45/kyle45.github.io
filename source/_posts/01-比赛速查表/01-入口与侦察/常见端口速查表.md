# 常见端口速查表

| 端口 | 协议/服务 | 比赛中优先检查 |
|---|---|---|
| 20/21 | FTP | 匿名登录、目录、可下载/上传文件、备份 |
| 22 | SSH | 用户名、密码、SSH Key、密码复用 |
| 23 | Telnet | 弱口令、明文认证 |
| 25 | SMTP | 邮箱信息、用户枚举、邮件内容 |
| 53 | DNS | DNS信息、区域传送、内部域名 |
| 67/68 | DHCP | DHCP信息、网络配置 |
| 69 | TFTP | 是否允许匿名读写、配置/固件 |
| 80 | HTTP | Web、目录枚举、常见Web漏洞 |
| 110 | POP3 | 邮箱认证、邮件内容 |
| 111 | RPCbind | RPC服务枚举、NFS |
| 123 | NTP | 时间服务、配置错误 |
| 135 | MSRPC | Windows RPC、进一步枚举 |
| 137-139 | NetBIOS/SMB | 主机名、共享、用户信息 |
| 143 | IMAP | 邮箱、认证信息 |
| 161 | SNMP | 社区字符串、系统信息、网络设备信息 |
| 389 | LDAP | 目录信息、用户、组织结构 |
| 443 | HTTPS | Web，注意证书、虚拟主机、后台 |
| 445 | SMB | 共享、匿名访问、用户/域信息 |
| 465/587 | SMTP | 邮件服务、认证 |
| 500 | IKE/IPsec | VPN相关信息 |
| 636 | LDAPS | LDAP over TLS |
| 873 | rsync | 模块、匿名访问、文件 |
| 993 | IMAPS | 加密邮箱 |
| 995 | POP3S | 加密邮箱 |
| 1080 | SOCKS | 代理服务、是否可作为跳板 |
| 1433 | MSSQL | 数据库认证、数据库信息 |
| 1521 | Oracle | SID、数据库认证 |
| 2049 | NFS | 共享目录、挂载权限 |
| 2181 | ZooKeeper | 信息泄露、服务配置 |
| 2375 | Docker API | 是否暴露Docker管理接口 |
| 2376 | Docker TLS | Docker API |
| 3000 | Node/Grafana等 | Web、管理后台 |
| 3306 | MySQL/MariaDB | 弱口令、数据库、业务数据 |
| 3389 | RDP | Windows远程桌面、凭据 |
| 4444 | 常见临时/实验服务 | 注意是否为题目自定义服务 |
| 5000 | Flask/开发Web等 | Web、调试接口 |
| 5432 | PostgreSQL | 数据库认证、业务数据 |
| 5601 | Kibana | Web、Elasticsearch数据 |
| 5900 | VNC | 远程桌面、认证 |
| 5985 | WinRM HTTP | Windows远程管理 |
| 5986 | WinRM HTTPS | Windows远程管理 |
| 6379 | Redis | 认证、缓存、Session、配置 |
| 6443 | Kubernetes API | K8s API、认证配置 |
| 8000 | Web/开发服务器 | Web、调试页面 |
| 8080 | HTTP Proxy/Tomcat/后台 | Web、管理后台、代理 |
| 8081 | Web/管理服务 | 后台、API |
| 8443 | HTTPS/管理后台 | Web管理界面 |
| 8888 | Jupyter/开发Web等 | Web、管理接口 |
| 9000 | PHP-FPM/开发服务等 | 服务识别、Web后端 |
| 9200 | Elasticsearch | 集群信息、索引、数据 |
| 9300 | Elasticsearch | 集群通信 |
| 10000 | Webmin | 管理后台、版本 |
| 11211 | Memcached | 缓存数据、配置 |
| 27017 | MongoDB | 数据库认证、数据库信息 |
| 50000 | IBM DB2等 | 数据库/特定服务识别 |
