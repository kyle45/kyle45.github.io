# 提权速查

> 适用场景：已经拿到低权限 Shell，需要快速判断 Linux / Windows 的提权路线。

## 第一分钟

Linux：

```bash
whoami; id
hostname
uname -a
cat /etc/os-release 2>/dev/null
sudo -l
```

Windows：

```cmd
whoami
whoami /priv
systeminfo
net user
net localgroup administrators
```

## Linux 提权顺序

1. `sudo -l`：看免密命令、可编辑脚本、环境变量保留。
2. SUID：
   ```bash
   find / -perm -u=s -type f 2>/dev/null
   ```
   对照 [GTFOBins](https://gtfobins.github.io/) 找利用方式。
3. Capabilities：
   ```bash
   getcap -r / 2>/dev/null
   ```
4. 计划任务：
   ```bash
   cat /etc/crontab
   crontab -l
   ls -la /etc/cron*
   ```
5. 可写文件 / 目录 / 服务配置：
   ```bash
   find / -writable -type f 2>/dev/null | head -100
   find / -perm -002 -type d 2>/dev/null | head -100
   ```
6. 环境变量、PATH、`LD_PRELOAD`、`LD_LIBRARY_PATH`。
7. 历史记录、配置文件、SSH 私钥、数据库密码、Token。
8. 内核版本与对应 CVE。
9. Docker / Kubernetes / 容器逃逸。
10. 以上都不行时再跑 `linpeas.sh`。

## Windows 提权顺序

1. `whoami /priv`：重点看 `SeImpersonatePrivilege`、`SeAssignPrimaryTokenPrivilege`。
2. 补丁与系统版本：
   ```cmd
   systeminfo
   wmic qfe get HotFixID
   Get-HotFix
   Get-CimInstance Win32_QuickFixEngineering
   ```
3. 服务权限：
   ```cmd
   wmic service get name,displayname,pathname,startmode
   ```
4. 计划任务、启动项、可写目录、未引用服务路径。
5. 注册表：
   ```cmd
   reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
   reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders
   reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
   ```
6. Potato 系：`SweetPotato`、`JuicyPotato`、`GodPotato`。
7. 数据库：MSSQL `xp_cmdshell`、MySQL UDF。
8. 凭据：`mimikatz`、浏览器密码、配置文件、`unattend.xml`、`web.config`。

## 判断原则

- 先找“配置错误”，再找“服务权限”，最后再考虑内核漏洞。
- 拿到 `root/SYSTEM` 后立即确认：`id` / `whoami`，再读 Flag 或继续信息收集。
- 提权不是终点：优先回头找凭据、内网路由和下一跳目标。
