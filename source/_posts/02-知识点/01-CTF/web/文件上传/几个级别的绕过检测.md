# 文件上传绕过层级

## 1. 前端校验

- 删除 `onsubmit` 或修改 JavaScript。
- 使用 Burp 直接改包。
- 文件名和 MIME 同时修改。

## 2. MIME / Content-Type

```text
Content-Type: image/png
Content-Type: image/jpeg
```

部分环境还会检查文件头，因此需要同时准备合法文件头。

## 3. 黑名单绕过

- 大小写：`pHp`。
- 等价后缀：`php3`、`php4`、`php5`、`phtml`、`pht`。
- 多重扩展名：`shell.php.jpg`、`shell.jpg.php`。
- 特殊字符：`shell.php.`、`shell.php%00.jpg`（受版本限制）。
- 解析配置：`.htaccess`、`.user.ini`。

## 4. 白名单绕过

- 内容检测与文件头伪造。
- 图片马配合文件包含。
- 压缩包、解析漏洞或中间件特性。
- 路径穿越导致保存目录和访问路径不一致。

## 5. 验证要点

- 修改后需要确认服务端实际保存的文件名。
- 检查上传目录能否直接访问。
- 检查 Web 服务器和 PHP 的解析顺序。
