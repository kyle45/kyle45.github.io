# Web 爆破

## 常见目标

- 目录和文件。
- 子域名和虚拟主机。
- 登录口令。
- 参数名和参数值。
- API 路径、Token 和验证码接口。

## 常用工具

```bash
ffuf -u http://target/FUZZ -w wordlist.txt
dirsearch -u http://target -e php,html,js,txt,bak,zip
hydra -l admin -P pass.txt http-post-form "/login:username=^USER^&password=^PASS^:F=invalid"
wfuzz -c -w subdomains.txt -H "Host: FUZZ.target" http://target
```

## 常用字典位置

```text
/usr/share/wordlists/
/usr/share/seclists/
/usr/share/dirb/wordlists/
```

## 原则

- 先小字典验证，再扩大字典。
- 过滤状态码、响应长度和跳转，减少噪声。
- 对登录接口先确认失败特征，再选择 `F=` 或 `S=`。
