# PHP正则

在PHP中，正则表达式的模式（Pattern）是用来定义搜索规则的字符串。它通常由三部分组成：**定界符**、**子模式**和**修饰符**。掌握这三个部分是高效使用PHP正则表达式的关键。

***

### 1. 定界符 (Delimiters)

定界符用来标记正则表达式的开始和结束。在PHP中，最常用的定界符是斜杠`/`，但你也可以使用其他非字母、数字、反斜杠或空白字符的符号，比如`#`、`~`或`|`。

**示例：**

* `/pattern/`
* `#pattern#`

**注意：** 如果你的模式中包含定界符本身，你需要用反斜杠`\`对其进行转义。例如，如果你想匹配一个URL路径，可以使用`#`作为定界符来避免对`/`进行转义：`#^/path/to/file#`。

***

### 2. 子模式 (Subpattern)

子模式是正则表达式的核心，由各种**元字符**、**字符类**和**量词**等组成。它们共同定义了你想要匹配的具体内容。

#### **元字符 (Metacharacters)**

元字符有特殊的含义，可以用来匹配特定位置或类型的字符。

| 元字符 | 含义 |
| :--- | :--- |
| `.` | 匹配除换行符以外的任何单个字符 |
| `^` | 匹配字符串的开头 |
| `$` | 匹配字符串的结尾 |
| `*` | 匹配前一个字符0次或多次 |
| `+` | 匹配前一个字符1次或多次 |
| `?` | 匹配前一个字符0次或1次 |
| `[ ]` | 字符类，匹配方括号内的任意一个字符 |
| `( )` | 分组，将模式中的多个部分组合成一个整体 |
| `|` | 或，匹配`|`符号左边或右边的表达式 |
| `\` | 转义字符，将特殊字符转换为普通字符 |

**示例：**

* `/^hello/` 匹配以"hello"开头的字符串。
* `/go+gle/` 匹配"gogle"、"google"、"gooogle"等。
* `/col(o|ou)r/` 匹配"color"或"colour"。

***

#### **字符类 (Character Classes)**

字符类用方括号`[ ]`定义，用于匹配方括号内的**任意一个**字符。

| 字符类 | 含义 |
| :--- | :--- |
| `[abc]` | 匹配`a`、`b`或`c`中的任意一个 |
| `[a-z]` | 匹配小写字母`a`到`z` |
| `[0-9]` | 匹配数字`0`到`9` |
| `[^abc]` | 匹配除`a`、`b`、`c`以外的任意一个字符 |

***

#### **预定义字符类**

为了方便，PHP还提供了一些预定义的字符类。

| 预定义字符类 | 含义 |
| :--- | :--- |
| `\d` | 匹配任何一个数字字符，等同于`[0-9]` |
| `\D` | 匹配任何一个非数字字符，等同于`[^0-9]` |
| `\w` | 匹配任何一个单词字符（字母、数字或下划线），等同于`[a-zA-Z0-9_]` |
| `\W` | 匹配任何一个非单词字符 |
| `\s` | 匹配任何一个空白字符（空格、制表符、换行符等） |
| `\S` | 匹配任何一个非空白字符 |

**示例：**

* `/\d{3}-\d{4}/` 匹配电话号码格式，如"123-4567"。

***

### 3. 修饰符 (Modifiers)

修饰符位于正则表达式的**末尾**，定界符之后，用来改变匹配的行为。

| 修饰符 | 含义 |
| :--- | :--- |
| `i` | **忽略大小写**（**i**nsensitive） |
| `m` | **多行模式**（**m**ultiline），让`^`和`$`匹配每一行的开头和结尾 |
| `s` | **单行模式**（`**.**`\*\* 匹配换行符\*\*） |
| `g` | **全局匹配**（**g**lobal），在PHP中，通常由`preg_match_all()`函数来替代，用于找到所有匹配项 |
| `u` | **Unicode模式**，正确处理UTF-8编码的字符串 |

**示例：**

* `/hello/i` 可以匹配 "Hello"、"HELLO" 或 "hello"。
* `/^start$/m` 在多行字符串中，可以匹配每一行只包含"start"的行。

掌握这些基础知识，可以帮助你构建出强大而灵活的PHP正则表达式模式。
