# 图片隐写

## 基本信息

```bash
file image.png
identify -verbose image.png
exiftool image.png
```

## 常见方向

- 文件头、文件尾和附加数据。
- EXIF、注释、作者和 GPS。
- LSB、颜色通道和调色板。
- 图层、Alpha 通道和透明度。
- 图片尺寸、像素值和二维码。
- 文件拼接、伪加密和压缩包附加。

## 常用工具

```bash
binwalk -e image.png
foremost image.png
zsteg image.png
steghide extract -sf image.jpg
pngcheck -v image.png
```

## 排查顺序

1. 基础信息。
2. `strings` 和 `binwalk`。
3. 隐写工具。
4. 逐通道分析。
5. 结合题目提示判断编码或密码。
