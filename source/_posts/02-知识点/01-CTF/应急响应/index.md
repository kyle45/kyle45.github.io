# 应急响应

## Windows

- [Windows 排查与处置](Windows.md)

## 常见排查入口

| 方向 | 重点 |
|---|---|
| 账号 | 新增用户、管理员组变化、异常登录 |
| 进程 | 异常父进程、无签名程序、临时目录进程 |
| 网络 | 异常监听、外联 IP、代理与隧道 |
| 持久化 | 服务、计划任务、启动项、注册表 Run |
| Web | 上传目录、日志、后门文件、异常请求 |
| 日志 | 4624 / 4625 / 4648 / 4688 / 7045 |

## 基本处置顺序

1. 隔离主机并保留现场。
2. 记录账号、进程、端口、服务和计划任务。
3. 定位入口和时间线。
4. 提取 IOC 与样本 Hash。
5. 清除持久化、修改凭据、恢复业务。
