# 常见思路

1. nmap 端口发现
2. dirsearch 目录爆破

dirsearch -u url -w dict.txt -e txt  -f

+ -e 只扫txt扩展名的
+ -f 对于没有txt结尾的，主动加上txt
3. wfuzz 子域名发现 
+ wfuzz -c -f sub.txt -w /usr/share/wordlists/dirb/common.txt -u '[http://team.thm'](http://team.thm') -H 'Host: FUZZ.team.thm' --hc 404,400 --hw 977
+ -c 输出显示优化
+ -f 输出到文件
+ -w 字典
+ -H
+ -hc hide code 隐藏返回404 400的
+ -hw hide word 隐藏977长度的返回包
