# 隧道软件

## stowaway

只能一个agent连admin

### 命令

云主机：`./stowaway_admin -l 7000`

客户端：`./stowaway_agent -c 124.71.111.64:7000`

服务端：`> use 0 `

服务端：`> socks 7500`

其他机器直接设置`socks5`代理为`124.71.111.64:7500`即可

## frp

### 命令

`./frpc -c ./frpc.toml`

`./frps -c ./frps.toml`

### 配置文件

云主机：

```toml
bindPort = 7000
[auth]
token = "121212"
```

客户端A（代理端）：

```toml
serverAddr = "106.52.146.132"
serverPort = 7000

[auth]
token = "121212"

[[proxies]]
name = "socks5"
type = "tcp"
remotePort = 7500

  [proxies.plugin]
  type = "socks5"
  # user = "your_proxy_user"     # 可选
  # passwd = "your_proxy_passwd" # 可选
```

客户端B：

```toml
serverAddr = "127.0.0.1"
serverPort = 7000
[auth]
token = "121212"
```

## nps

1. 客户端`./npc -server=106.52.146.132:7000 -vkey=wu6a148xkwastp43 -type=tcp`
2. 服务端
3. 最小可用 nps.conf（socks5 + http代理 + web）

```toml
appname = nps
runmode = pro

# Web界面
web_username = admin
web_password = web_password
web_port = 7500

# 桥接配置
bridge_type = tcp
bridge_port = 7000
auth_key = your_private_auth_key_string
auth_crypt = false

# 日志（保持为空以避免 BeeLogger 报错）不注释会报错
# log_path =
# log_level = INFO

# IP限制
ip_limit = true
ip_limit_count = 500

# socks5/HTTP代理
socks5_proxy_port = 7600
http_proxy_port = 7700
```

4. 权限设置

`sudo chown -R root:root /home/kyle/nps`

`sudo chmod -R 700 /home/kyle/nps`

5. 配置 systemd 服务

```toml
[Unit]
Description=NPS Server
After=network.target

[Service]
Type=simple
WorkingDirectory=/home/kyle/nps
ExecStart=/home/kyle/nps/nps
Restart=on-failure
User=root

[Install]
WantedBy=multi-user.target
```

6. systemd开机自启动

`sudo systemctl daemon-reload`# 重新加载 systemd

`sudo systemctl start nps`# 启动服务

`sudo journalctl -u nps -f`# 查看实时日志

`sudo systemctl enable nps`# 设置开机自启
