# 实战靶场提权

## Linux 快速检查

```bash
id
sudo -l
uname -a
find / -perm -u=s -type f 2>/dev/null
getcap -r / 2>/dev/null
cat /etc/crontab
crontab -l
```

## Windows 快速检查

```cmd
whoami /priv
systeminfo
net user
net localgroup administrators
wmic service get name,displayname,pathname,startmode
```

## 常用方向

- Linux：SUID、sudo、Capabilities、计划任务、内核、环境变量、容器逃逸。
- Windows：SeImpersonate、服务权限、未引用服务路径、计划任务、注册表、Potato 系。
- 数据库：MySQL UDF、MSSQL `xp_cmdshell`。
- 域：DCSync、黄金票据、AD CS、委派。
